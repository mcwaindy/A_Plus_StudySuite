## 📌 Overview

Windows systems can experience a wide range of issues related to hardware, drivers, services, profiles, memory, and boot processes. Core 2 requires recognizing symptoms, identifying root causes, and applying the correct troubleshooting steps based on the scenario.

---

## 💥 Blue Screen of Death (BSOD)

**Symptoms:** Sudden crash with error code (e.g., `IRQL_NOT_LESS_OR_EQUAL`).  
**Causes:**  
* Faulty drivers  
* Hardware failure (RAM, CPU, GPU)  
* Corrupt system files  
* Overheating  
* Malware  

**Fixes:**  
* Check Event Viewer  
* Update or roll back drivers  
* Run memory diagnostics  
* Run `sfc /scannow` and `DISM`  
* Check hardware temperatures  

---

## 🐌 Degraded Performance

**Symptoms:** Slow apps, lag, freezing.  
**Causes:**  
* Too many startup apps  
* Low RAM  
* Malware  
* Disk fragmentation (HDD)  
* High CPU usage  

**Fixes:**  
* Task Manager → identify heavy processes  
* Disable startup apps  
* Run malware scan  
* Upgrade RAM  
* Check disk health (`chkdsk`)  

---

## 🚫 Boot Issues

**Symptoms:** System won’t boot, stuck at logo, looping restart.  
**Causes:**  
* Corrupt boot loader  
* Damaged OS files  
* Wrong boot order  
* Failed Windows update  
* Drive failure  

**Fixes:**  
* Boot to WinRE  
* Use Startup Repair  
* Run `bootrec /fixmbr`, `/fixboot`, `/rebuildbcd`  
* Check BIOS boot order  
* Test drive with SMART tools  

---

## 🔄 Frequent Shutdowns

**Symptoms:** Random shutdowns or restarts.  
**Causes:**  
* Overheating  
* Failing PSU  
* Driver conflicts  
* Malware  
* Faulty RAM  

**Fixes:**  
* Check temps with monitoring tools  
* Clean dust from fans  
* Test PSU  
* Update drivers  
* Run memory diagnostics  

---

## 🛑 Services Not Starting

**Symptoms:** Windows services fail to launch.  
**Causes:**  
* Disabled dependencies  
* Corrupt service configuration  
* Malware  
* Insufficient permissions  

**Fixes:**  
* Services.msc → check dependencies  
* Run `sfc /scannow`  
* Check Event Viewer  
* Ensure account permissions  

---

## 💥 Applications Crashing

**Symptoms:** Apps close unexpectedly or fail to launch.  
**Causes:**  
* Corrupt installation  
* Missing libraries (.NET, Visual C++)  
* Driver conflicts  
* Insufficient memory  

**Fixes:**  
* Reinstall application  
* Install required frameworks  
* Update drivers  
* Check logs in Event Viewer  

---

## 🧠 Low Memory Warnings

**Symptoms:** “Your computer is low on memory.”  
**Causes:**  
* Memory leak  
* Too many apps running  
* Insufficient RAM  
* Malware  

**Fixes:**  
* Task Manager → identify memory hogs  
* Increase virtual memory  
* Add physical RAM  
* Close background apps  

---

## 🔌 USB Controller Resource Warnings

**Symptoms:** USB devices not detected or error messages.  
**Causes:**  
* Too many USB devices  
* Insufficient power  
* Driver issues  
* Faulty USB controller  

**Fixes:**  
* Remove unused USB devices  
* Use powered USB hubs  
* Update chipset/USB drivers  
* Check Device Manager for conflicts  

---

## ⚠️ System Instability

**Symptoms:** Random freezes, crashes, inconsistent behavior.  
**Causes:**  
* Faulty RAM  
* Overheating  
* Corrupt OS files  
* Malware  
* Failing hardware  

**Fixes:**  
* Run diagnostics  
* Check temps  
* Run `sfc` and `DISM`  
* Update drivers  
* Replace failing components  

---

## ❌ No OS Found

**Symptoms:** BIOS error: “Operating System Not Found.”  
**Causes:**  
* Wrong boot device  
* Corrupt boot sector  
* Drive failure  
* Loose cables  

**Fixes:**  
* Check BIOS boot order  
* Run bootrec commands  
* Test drive health  
* Reseat SATA/NVMe connections  

---

## 🐢 Slow Profile Load

**Symptoms:** Long login times.  
**Causes:**  
* Corrupt user profile  
* Network issues (domain profiles)  
* Large roaming profile  
* Slow disk  

**Fixes:**  
* Create new profile  
* Check network connectivity  
* Reduce profile size  
* Upgrade to SSD  

---

## ⏱ Time Drift

**Symptoms:** System clock slowly becomes inaccurate.  
**Causes:**  
* Disabled Windows Time service  
* Incorrect time zone  
* CMOS battery failure  
* NTP server issues  

**Fixes:**  
* Restart Windows Time service  
* Correct time zone  
* Replace CMOS battery  
* Sync with reliable NTP server  

---

## ⚡ Key Vocabulary

BSOD  
: Critical system crash caused by hardware or driver failure.

Bootrec  
: Command-line tool for repairing boot loaders.

Profile Corruption  
: Damaged user profile causing slow logins or errors.

Time Drift  
: Gradual loss of clock accuracy due to sync or hardware issues.

---

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: BSOD Causes"
    BSODs almost always point to **drivers**, **hardware**, or **corrupt system files**.

!!! danger "Common Pitfall: Ignoring Boot Order"
    “No OS found” often means the BIOS is booting the wrong device.

!!! tip "Remember: Slow Profile Load"
    Domain profiles depend on network speed — check connectivity first.

!!! warning "Watch Out: Time Drift"
    Time drift breaks authentication systems like Kerberos — fix clock issues immediately.

!!! example "Scenario: Apps Crash After Update"
    **Scenario:** After a Windows update, multiple apps crash on launch.  
    **Solution:** Roll back drivers, reinstall frameworks, and check Event Viewer for faulting modules.
