## 📌 Overview

Windows command-line tools provide powerful capabilities for navigation, file management, disk operations, networking diagnostics, and system administration. Core 2 requires knowing which command to use in a given scenario and understanding the output each tool provides.

---

## 📂 Navigation Commands

### cd
* Changes the current directory.
* Supports absolute and relative paths.
* Example: `cd C:\Windows\System32`

### dir
* Lists files and folders in the current directory.
* Supports switches such as `/a`, `/s`, `/p`.

---

## 🌐 Network Commands

### ipconfig
* Displays IP configuration details.
* Common uses:
  * `ipconfig /all` — full network details
  * `ipconfig /release` / `ipconfig /renew` — DHCP troubleshooting
  * `ipconfig /flushdns` — clears DNS cache

### ping
* Tests connectivity to a host.
* Useful for verifying network reachability and latency.

### netstat
* Displays active connections and listening ports.
* Useful for identifying suspicious network activity.

### nslookup
* Queries DNS servers for hostname/IP resolution.
* Helps diagnose DNS failures.

### net use
* Maps network drives or displays existing connections.
* Example: `net use Z: *server\share`

### tracert
* Shows the path packets take to a destination.
* Useful for identifying routing issues.

### pathping
* Combines ping + tracert.
* Provides packet loss statistics at each hop.

## 💽 Disk Management Commands

### chkdsk
* Checks disk integrity and repairs file system errors.
* Example: `chkdsk /f` — fixes errors  
  `chkdsk /r` — locates bad sectors

### format
* Formats a drive with a specified filesystem.
* Example: `format E: /fs:NTFS`

### diskpart
* Advanced disk partitioning tool.
* Used for:
  * Creating/deleting partitions
  * Cleaning drives
  * Converting MBR ↔ GPT

---

## 📁 File Management Commands

### md
* Creates a new directory.
* Example: `md Projects`

### rmdir
* Removes a directory.
* Use `/s` to remove directory and contents.

### robocopy
* Robust file copy utility.
* Supports mirroring, retries, logging, and multithreaded copying.
* Example: `robocopy C:\source D:\dest /mir`

---

## 🧾 Informational Commands

### hostname
* Displays the computer’s name.

### net user
* Shows user accounts or modifies them.
* Example: `net user Dylan /add`

### winver
* Displays Windows version and build information.

### whoami
* Shows the current logged-in user and security context.

### [command] /?
* Displays help and usage information for any command.
* Example: `ipconfig /?`

---

## ⚙️ OS Management Commands

### gpupdate
* Applies Group Policy changes immediately.
* Example: `gpupdate /force`

### gpresult
* Displays applied Group Policy settings for a user or computer.
* Example: `gpresult /r`

### sfc
* System File Checker — scans and repairs corrupted system files.
* Example: `sfc /scannow`

---

## ⚡ Key Vocabulary

CLI  
: Command-line interface used for text-based system control.

Diskpart  
: Advanced disk partitioning tool replacing older utilities like fdisk.

Robocopy  
: High-performance file copy tool with advanced options for backups and mirroring.

SFC  
: System File Checker used to repair corrupted Windows system files.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: DNS Troubleshooting"
    If a scenario mentions **hostname not resolving**, the correct tool is **nslookup** — not ping.

!!! danger "Common Pitfall: Using format Incorrectly"
    `format` **erases all data**. If a scenario mentions preserving data, choose **chkdsk** or **diskpart** operations instead.

!!! tip "Remember: robocopy vs. copy"
    `copy` is basic.  
    `robocopy` is **enterprise-grade**, supports retries, logging, and mirroring.

!!! warning "Watch Out: diskpart Clean"
    `diskpart clean` removes all partitions. If a scenario mentions accidental data loss, this may be the cause.

!!! example "Scenario: Group Policy Not Applying"
    **Scenario:** A user reports that new Group Policy settings are not taking effect.  
    **Solution:** Run **gpupdate /force**, then verify with **gpresult /r**.
