## 📌 Overview

Mobile devices introduce unique security risks due to portability, wireless connectivity, and personal data storage. Core 2 requires understanding how to harden mobile devices, apply patch management, configure endpoint security, and enforce policies through MDM or corporate governance.

---

## 🔐 Hardening Techniques

### Device Encryption
* Protects data-at-rest.
* Prevents unauthorized access if device is lost or stolen.
* Examples:
  * **Android:** Full-disk or file-based encryption
  * **iOS:** Hardware-backed encryption enabled by default

### Screen Locks
Used to prevent unauthorized access.

#### Facial Recognition
* Biometric authentication.
* Fast and convenient.

#### PIN Codes
* Minimum recommended length: 6 digits.
* More secure than swipe or pattern.

#### Fingerprint
* Biometric authentication using capacitive or ultrasonic sensors.

#### Pattern
* Visual unlock method; less secure due to smudge tracing.

#### Swipe
* No security; should not be used on corporate devices.

### Configuration Profiles
* Enforce security settings via:
  * Password requirements
  * Wi-Fi/VPN configurations
  * App restrictions
  * Certificate deployment
* Managed through MDM solutions.

---

## 🔄 Patch Management

### OS Updates
* Critical for fixing vulnerabilities.
* Should be applied automatically or on a scheduled basis.

### Application Updates
* Prevent exploitation of outdated apps.
* Includes browser, email, and productivity apps.

---

## 🛡 Endpoint Security Software

### Antivirus
* Detects known malware signatures.

### Anti-Malware
* Detects broader threat categories including spyware and adware.

### Content Filtering
* Blocks malicious websites.
* Prevents phishing and unsafe browsing.

---

## 📍 Locator Applications

* Track device location.
* Examples:
  * Find My iPhone
  * Find My Device (Android)
* Useful for:
  * Lost/stolen device recovery
  * Remote lock or wipe

---

## 🧹 Remote Wipes

* Erases all data on a lost or compromised device.
* Can be triggered via:
  * MDM console
  * iCloud/Google account
* Protects sensitive corporate or personal data.

---

## ☁️ Remote Backup Applications

* Cloud backups ensure data recovery.
* Examples:
  * iCloud Backup
  * Google One Backup
* Protects against:
  * Device loss
  * Hardware failure
  * Malware corruption

---

## 🚫 Failed Log-In Attempts Restrictions

* Locks device after repeated failed attempts.
* Prevents brute-force attacks.
* Often configurable via MDM.

---

## 📜 Policies & Procedures

### Mobile Device Management (MDM)
* Centralized control over mobile devices.
* Enforces:
  * Encryption
  * Password policies
  * App restrictions
  * Remote wipe
  * Compliance monitoring

### BYOD vs. Corporate-Owned Devices

#### BYOD (Bring Your Own Device)
* User-owned devices used for work.
* Risks:
  * Limited control
  * Data leakage
  * Mixed personal/corporate data

#### Corporate-Owned Devices
* Fully managed by IT.
* Benefits:
  * Stronger security enforcement
  * Standardized configurations
  * Full MDM control

### Profile Security Requirements
* Enforced through configuration profiles.
* May include:
  * Mandatory encryption
  * Minimum password complexity
  * Restricted app installation
  * VPN requirements
  * Certificate-based authentication

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: BYOD vs. Corporate-Owned"
    BYOD requires **lighter control** and privacy considerations.  
    Corporate-owned devices allow **strict enforcement** via MDM.

!!! danger "Common Pitfall: Weak Screen Locks"
    Swipe and simple patterns are insecure — corporate devices should use **PIN**, **fingerprint**, or **face unlock**.

!!! tip "Remember: Encryption"
    Encryption protects data-at-rest. If a scenario mentions a lost device, encryption is the correct mitigation.

!!! warning "Watch Out: Unpatched Apps"
    Many mobile compromises occur through outdated apps — patch management is critical.

!!! example "Scenario: Lost Corporate Phone"
    **Scenario:** An employee loses a company-issued phone containing sensitive data.  
    **Solution:** Use **locator app**, then perform a **remote wipe** via MDM.
