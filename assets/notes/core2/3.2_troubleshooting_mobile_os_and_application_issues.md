## 📌 Overview

Mobile devices experience issues related to apps, OS updates, connectivity, battery performance, and hardware sensors. Core 2 requires identifying symptoms, determining root causes, and applying the correct troubleshooting steps based on the scenario.

---

## 📱 Application Fails to Launch

**Symptoms:** App won’t open, freezes on splash screen.  
**Causes:**  
* Corrupt app data  
* Outdated app version  
* OS compatibility issues  
* Insufficient memory  

**Fixes:**  
* Force close and relaunch  
* Clear app cache/data (Android)  
* Reinstall the app  
* Update OS and app  
* Restart device  

---

## ❌ Application Fails to Close / Crashes

**Symptoms:** App freezes, force closes, or loops.  
**Causes:**  
* Memory leak  
* Buggy update  
* Corrupt installation  
* Conflicting background processes  

**Fixes:**  
* Force stop the app  
* Clear cache/data  
* Update or reinstall  
* Check for OS updates  
* Restart device  

---

## 🔄 Application Fails to Update

**Symptoms:** Update stuck, error message, insufficient storage.  
**Causes:**  
* Low storage  
* Poor connectivity  
* App store issues  
* OS version incompatibility  

**Fixes:**  
* Free up storage  
* Switch to Wi-Fi  
* Restart app store  
* Update OS  
* Clear app store cache (Android)  

---

## 📥 Application Fails to Install

**Symptoms:** Install fails or stalls.  
**Causes:**  
* Insufficient storage  
* Unsupported OS version  
* App store restrictions  
* Corrupt download  

**Fixes:**  
* Free storage  
* Check OS compatibility  
* Restart device  
* Try reinstalling  
* Clear app store cache  

---

## 🐌 Slow to Respond

**Symptoms:** Lag, freezing, delayed input.  
**Causes:**  
* Too many background apps  
* Low RAM  
* Overheating  
* Malware (rare on mobile)  

**Fixes:**  
* Close background apps  
* Restart device  
* Update OS  
* Check storage usage  
* Remove unused apps  

---

## ⚙️ OS Fails to Update

**Symptoms:** Update fails, error codes, stuck on download.  
**Causes:**  
* Low battery  
* Insufficient storage  
* Poor connectivity  
* Server issues  
* Jailbroken/rooted device  

**Fixes:**  
* Charge device  
* Free storage  
* Connect to stable Wi-Fi  
* Restart device  
* Use computer-based update (iTunes/Finder, OEM tools)  

---

## 🔋 Battery Life Issues

**Symptoms:** Fast drain, overheating, inaccurate battery percentage.  
**Causes:**  
* Background apps  
* High screen brightness  
* Old battery  
* Rogue apps  
* Poor signal strength  

**Fixes:**  
* Enable battery saver  
* Reduce brightness  
* Disable background refresh  
* Check battery health  
* Replace battery if needed  

---

## 🔁 Random Reboots

**Symptoms:** Device restarts unexpectedly.  
**Causes:**  
* OS corruption  
* Faulty apps  
* Overheating  
* Hardware failure  
* Low battery health  

**Fixes:**  
* Update OS  
* Remove problematic apps  
* Check battery health  
* Factory reset if persistent  

---

## 📡 Connectivity Issues

### Bluetooth
**Symptoms:** Won’t pair, disconnects.  
**Fixes:**  
* Toggle Bluetooth  
* Forget and re-pair device  
* Restart both devices  
* Update OS  

### Wi-Fi
**Symptoms:** No connection, slow speeds.  
**Fixes:**  
* Toggle Wi-Fi  
* Forget network  
* Restart router  
* Reset network settings  

### NFC
**Symptoms:** Tap-to-pay fails, no detection.  
**Fixes:**  
* Ensure NFC is enabled  
* Remove thick cases  
* Align NFC antenna properly  
* Restart device  

---

## 🔄 Screen Does Not Autorotate

**Symptoms:** Screen stuck in portrait/landscape.  
**Causes:**  
* Rotation lock enabled  
* Sensor malfunction  
* App-specific restriction  

**Fixes:**  
* Disable rotation lock  
* Restart device  
* Test with multiple apps  
* Run hardware diagnostics  

---

## ⚡ Key Vocabulary

Background Refresh  
: Feature allowing apps to update content in the background.

Network Reset  
: Clears Wi-Fi, Bluetooth, and cellular settings.

Battery Health  
: Measurement of battery capacity relative to new.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Storage Issues"
    Many mobile problems — failed installs, updates, crashes — are caused by **low storage**.

!!! danger "Common Pitfall: Ignoring Network Settings"
    Connectivity issues often require **network reset**, not just toggling Wi-Fi/Bluetooth.

!!! tip "Remember: Autorotate"
    If autorotate fails, check **rotation lock** first — simplest fix.

!!! warning "Watch Out: App Crashes After Update"
    Reinstalling the app is often the correct answer.

!!! example "Scenario: Tap-to-Pay Stops Working"
    **Scenario:** A user’s NFC payments suddenly fail.  
    **Solution:** Ensure NFC is enabled, remove bulky case, restart device, and test with another terminal.
