## 📌 Overview

Cloud-based productivity tools provide email, storage, collaboration, and communication services delivered through SaaS platforms such as Microsoft 365 and Google Workspace. Core 2 requires understanding how to install, configure, and manage these tools, including identity synchronization and licensing assignment.

---

## 📧 Email Systems

Cloud email platforms include:
* **Microsoft 365 Exchange Online**
* **Google Workspace Gmail**
* **Hosted IMAP/POP services**

Key configuration tasks:
* Add accounts to mail clients (Outlook, Apple Mail, Thunderbird)
* Configure:
  * Incoming/outgoing servers
  * Authentication methods (OAuth, modern auth)
  * Sync settings (IMAP vs. Exchange ActiveSync)
* Apply security policies (MFA, conditional access)

---

## ☁️ Cloud Storage

### Sync / Folder Settings
Cloud storage platforms include:
* OneDrive
* Google Drive
* Dropbox
* Box

Configuration tasks:
* Select folders to sync (Selective Sync)
* Manage:
  * Offline availability
  * Version history
  * Sharing permissions
* Resolve sync conflicts
* Configure backup folders (Desktop/Documents/Pictures)

## 🔐 Identity Synchronization

Identity sync ensures users authenticate consistently across cloud services.

Common methods:
* **Azure AD Connect**  
  * Syncs on-prem Active Directory → Azure AD
* **Google Cloud Directory Sync (GCDS)**
* **Single Sign-On (SSO)**  
  * SAML  
  * OAuth  
  * OpenID Connect

Benefits:
* Unified credentials  
* Centralized password policies  
* MFA enforcement  
* Seamless access across devices

---

## 🪪 Licensing Assignment

Cloud platforms require assigning licenses to users to enable services.

Tasks include:
* Assigning Microsoft 365 licenses (Business, E3, E5)
* Assigning Google Workspace tiers (Business Starter, Standard, Plus)
* Managing:
  * Add-ons (Teams Phone, storage upgrades)
  * Revoking licenses for offboarding
  * Tracking license usage and availability

Licensing determines:
* Email mailbox size  
* App availability  
* Security features  
* Compliance tools

## ⚡ Key Vocabulary

SaaS  
: Software delivered over the internet, managed entirely by the provider.

Identity Sync  
: Process of synchronizing user accounts between on-prem and cloud directories.

Selective Sync  
: Cloud storage feature allowing users to choose which folders sync locally.

SSO  
: Single Sign-On — one login grants access to multiple cloud services.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Identity Sync"
    If a scenario mentions **on-prem Active Directory + cloud accounts**, the correct tool is **Azure AD Connect** for synchronization.

!!! danger "Common Pitfall: Missing License"
    If a user cannot access Teams, OneDrive, or email, check **license assignment** before troubleshooting the app.

!!! tip "Remember: Selective Sync"
    Cloud storage sync issues often stem from folders not being selected for sync.

!!! warning "Watch Out: MFA Requirements"
    Many cloud apps require MFA. If login fails after migration, verify MFA enrollment.

!!! example "Scenario: User Cannot Access Shared Documents"
    **Scenario:** A user reports they cannot open shared files in OneDrive.  
    **Solution:** Verify:
    * License assignment  
    * Folder sync settings  
    * Sharing permissions  
    * Identity synchronization status
