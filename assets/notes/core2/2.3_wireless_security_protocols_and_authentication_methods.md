## 📌 Overview

Wireless networks rely on encryption protocols and authentication methods to protect data in transit and ensure only authorized users can connect. Core 2 requires understanding the differences between WPA2, WPA3, TKIP, and AES, as well as authentication systems like RADIUS, TACACS+, Kerberos, and multifactor authentication.

---

## 🔐 Wireless Security Protocols & Encryption

### Wi‑Fi Protected Access 2 (WPA2)
* Industry standard for many years.
* Uses:
  * **AES** (recommended)
  * **TKIP** (legacy fallback)
* Vulnerable to certain attacks (KRACK), but still widely deployed.

### WPA3
* Latest Wi-Fi security standard.
* Improvements:
  * Stronger encryption
  * Protection against offline password cracking
  * SAE (Simultaneous Authentication of Equals) replaces PSK
* Required for modern devices and networks.

### Temporal Key Integrity Protocol (TKIP)
* Legacy encryption from WPA.
* Designed as a quick fix for WEP vulnerabilities.
* Considered insecure today.
* Should not be used unless required for compatibility.

### Advanced Encryption Standard (AES)
* Strong, modern encryption used in WPA2 and WPA3.
* Supports CCMP mode for integrity and confidentiality.
* Required for secure Wi-Fi deployments.

## 🔑 Authentication Methods

### Remote Authentication Dial-In User Service (RADIUS)
* Centralized authentication server.
* Used in enterprise Wi-Fi (WPA2/WPA3‑Enterprise).
* Supports:
  * User accounts
  * Certificates
  * Logging and auditing
* Integrates with Active Directory.

### Terminal Access Controller Access-Control System Plus (TACACS+)
* Cisco-developed authentication protocol.
* Used for device administration (routers, switches).
* Encrypts entire payload (more secure than RADIUS for admin tasks).
* Not typically used for Wi-Fi authentication.

### Kerberos
* Ticket-based authentication system.
* Used in Active Directory environments.
* Provides:
  * Mutual authentication
  * Single sign-on (SSO)
* Common in enterprise networks.

### Multifactor Authentication (MFA)
Requires two or more factors:

* Something you **know** (password)
* Something you **have** (token, phone)
* Something you **are** (biometrics)

Common MFA methods:
* Email code  
* Hardware token  
* Authenticator app  
* SMS code  
* Voice call  
* Time-based one-time password (TOTP)  
* One-time password/passcode (OTP)

## ⚡ Key Vocabulary

AES  
: Strong encryption used in WPA2/WPA3.

SAE  
: WPA3 authentication method replacing PSK.

RADIUS  
: Centralized authentication for enterprise Wi-Fi.

: Ticket-based authentication used in AD environments.

MFA  
: Authentication requiring multiple factors.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: WPA3 vs. WPA2"
    WPA3 uses **SAE** and stronger protections against offline attacks. If a scenario mentions “modern devices” or “highest security,” choose **WPA3**.

!!! danger "Common Pitfall: Using TKIP"
    TKIP is **not secure**. If a scenario mentions legacy devices, TKIP may be required — otherwise choose **AES**.

!!! tip "Remember: RADIUS for Enterprise Wi-Fi"
    WPA2/WPA3‑Enterprise **always** uses RADIUS for authentication.

!!! warning "Watch Out: Kerberos vs. TACACS+"
    Kerberos = user authentication (AD).  
    TACACS+ = device administration (network gear).

!!! example "Scenario: Company Wants Strong Wi-Fi Security"
    **Scenario:** A business wants to secure its wireless network with centralized authentication and strong encryption.  
    **Solution:** Use **WPA3‑Enterprise with AES + RADIUS**.
