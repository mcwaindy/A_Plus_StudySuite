## 📌 Overview

Backup and recovery processes protect data from loss due to corruption, hardware failure, malware, accidental deletion, or disaster. Core 2 requires understanding backup types, recovery methods, testing frequency, and rotation schemes used in SOHO and enterprise environments.

---

## 💾 Backup Types

### Full Backup
* Copies **all data** every time.
* Easiest to restore.
* Slowest and largest backup type.
* Foundation for all other backup strategies.

### Incremental Backup
* Copies **only data changed since the last backup** (full or incremental).
* Fastest and smallest backup type.
* Restore requires:
  * Last full backup  
  * Every incremental backup since  

### Differential Backup
* Copies **all data changed since the last full backup**.
* Larger than incremental, smaller than full.
* Restore requires:
  * Last full backup  
  * Latest differential backup  

### Synthetic Full Backup
* Creates a “virtual” full backup using:
  * Previous full backup  
  * Incremental backups  
* No need to run a full backup again.
* Faster and reduces storage usage.

---

## 🔁 Recovery Methods

### In-Place / Overwrite
* Restores data directly to the original location.
* Used when:
  * Files are corrupted  
  * Malware damaged data  
  * User accidentally deleted files  

### Alternative Location
* Restores data to a different folder or device.
* Useful for:
  * Comparing versions  
  * Partial recovery  
  * Avoiding overwriting good data  

---

## 🧪 Backup Testing

### Frequency
* Backups must be tested regularly to ensure:
  * Data integrity  
  * Successful restoration  
  * Proper versioning  
* Common testing intervals:
  * Monthly  
  * Quarterly  
  * After major system changes

## 🔄 Backup Rotation Schemes

### Onsite vs. Offsite

#### Onsite
* Stored locally (NAS, external drive).
* Fast recovery.
* Vulnerable to:
  * Fire  
  * Theft  
  * Flood  
  * Ransomware  

#### Offsite
* Stored remotely (cloud, secondary location).
* Protects against physical disasters.
* Slower recovery but more secure.

### Grandfather-Father-Son (GFS)
* Popular rotation scheme:
  * **Son:** Daily backups  
  * **Father:** Weekly backups  
  * **Grandfather:** Monthly backups  
* Provides long-term retention and multiple restore points.

### 3-2-1 Backup Rule
* **3** copies of data  
* **2** different storage media  
* **1** offsite copy  
* Industry standard for reliable backup protection.

## ⚡ Key Vocabulary

Incremental Backup  
: Saves only data changed since the last backup.

Synthetic Full  
: Full backup created from previous full + incremental backups.

GFS  
: Rotation scheme using daily, weekly, and monthly backups.

: Three copies, two media types, one offsite.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Incremental vs. Differential"
    Incremental = changes since **last backup**.  
    Differential = changes since **last full backup**.

!!! danger "Common Pitfall: No Offsite Backup"
    Onsite-only backups fail during disasters — always keep at least one offsite copy.

!!! tip "Remember: Synthetic Full"
    Synthetic full backups reduce time and storage by building a full backup from incrementals.

!!! warning "Watch Out: Backup Testing"
    Backups are useless if they can’t be restored — testing is mandatory.

!!! example "Scenario: Ransomware Attack"
    **Scenario:** A workstation is encrypted by ransomware.  
    **Solution:** Restore from **offsite backup** using the latest full + differential or incremental chain.
