## 📌 Overview

PC security issues often present as abnormal system behavior, blocked access, altered files, browser hijacking, or fake alerts. Core 2 requires identifying symptoms that indicate malware, unauthorized changes, or compromised system components — and applying the correct remediation steps.

---

## ⚠️ Common Security Symptoms

### Unable to Access the Network
**Symptoms:** No internet, limited connectivity, blocked access.  
**Causes:**  
* Malware modifying DNS  
* Firewall changes  
* Rogue proxy settings  
* Unauthorized VPN  
* Host file manipulation  

**Fixes:**  
* Reset network settings  
* Remove malicious proxy entries  
* Check firewall rules  
* Run anti-malware scan  

---

### Desktop Alerts
**Symptoms:** Unexpected pop-ups or warnings.  
**Causes:**  
* Scareware  
* Fake antivirus  
* Browser hijacking  
* Notification spam from malicious apps  

**Fixes:**  
* Close suspicious apps  
* Remove rogue programs  
* Clear browser data  
* Run anti-malware tools  

---

### False Alerts Regarding Antivirus Protection
**Symptoms:** “Your antivirus is out of date” or “Protection disabled” when it isn’t.  
**Causes:**  
* Fake antivirus  
* Malware attempting to disable real protection  
* Corrupt security services  

**Fixes:**  
* Verify antivirus status  
* Remove fake AV software  
* Run offline malware scan  
* Repair Windows Security services  

---

### Altered System or Personal Files

#### Missing/Renamed Files
**Causes:**  
* Ransomware  
* Malware deleting or hiding files  
* Unauthorized access  

**Fixes:**  
* Restore from backup  
* Remove malware  
* Check permissions  

#### Inability to Access Files
**Causes:**  
* Encryption by ransomware  
* Permission changes  
* Corrupt file system  

**Fixes:**  
* Identify ransomware type  
* Restore from backup  
* Repair permissions  

---

### Unwanted Notifications Within the OS
**Symptoms:** Ads, warnings, pop-ups unrelated to installed apps.  
**Causes:**  
* Adware  
* Browser hijackers  
* Malicious background apps  

**Fixes:**  
* Remove adware  
* Disable suspicious startup items  
* Clear browser extensions  

---

### OS Update Failures
**Symptoms:** Updates fail repeatedly or rollback.  
**Causes:**  
* Malware blocking updates  
* Corrupt system files  
* Disabled Windows Update service  
* Rootkits  

**Fixes:**  
* Run `sfc /scannow` and `DISM`  
* Remove malware  
* Restart update services  
* Use Windows Update Troubleshooter  

---

## 🌐 Browser-Related Security Symptoms

### Random/Frequent Pop-Ups
**Causes:**  
* Adware  
* Malicious extensions  
* Compromised browser settings  

**Fixes:**  
* Remove suspicious extensions  
* Clear cache and cookies  
* Reset browser settings  

---

### Certificate Warnings
**Symptoms:** “Certificate not trusted,” “Invalid certificate,” “Domain mismatch.”  
**Causes:**  
* Man-in-the-middle attacks  
* Malware altering HTTPS traffic  
* Expired certificates  
* Rogue proxy  

**Fixes:**  
* Remove malicious proxy  
* Reset browser  
* Verify site legitimacy  

---

### Redirection
**Symptoms:** Browser redirects to unknown sites.  
**Causes:**  
* Hijacked DNS  
* Malicious extensions  
* Hosts file manipulation  

**Fixes:**  
* Reset DNS settings  
* Remove extensions  
* Inspect hosts file  

---

### Degraded Browser Performance
**Symptoms:** Slow browsing, freezing, heavy CPU usage.  
**Causes:**  
* Adware  
* Excessive trackers  
* Malicious scripts  
* Too many extensions  

**Fixes:**  
* Remove unnecessary extensions  
* Clear browsing data  
* Run anti-malware scan  

---

## ⚡ Key Vocabulary

Scareware  
: Fake alerts designed to trick users into installing malware.

Browser Hijacker  
: Malware that modifies browser settings to redirect traffic.

Hosts File Manipulation  
: Unauthorized changes to local DNS mappings.

Fake Antivirus  
: Malicious software pretending to be security software.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Redirection"
    Browser redirection almost always points to **malicious extensions**, **DNS hijacking**, or **hosts file changes**.

!!! danger "Common Pitfall: Trusting Pop-Ups"
    Real Windows security alerts use consistent UI — pop-up ads or browser banners are **not legitimate**.

!!! tip "Remember: Update Failures"
    If Windows updates fail repeatedly, suspect **malware blocking updates** or **corrupt system files**.

!!! warning "Watch Out: Missing Files"
    Missing or renamed files strongly indicate **ransomware** or **malware tampering**.

!!! example "Scenario: Browser Shows Certificate Errors"
    **Scenario:** A user sees certificate warnings on multiple trusted sites.  
    **Solution:** Check for rogue proxy settings, remove malicious extensions, and reset DNS.
