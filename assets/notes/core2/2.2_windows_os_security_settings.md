## 📌 Overview

Windows provides built-in security tools to protect systems from malware, unauthorized access, data theft, and configuration tampering. Core 2 requires understanding how to configure antivirus, firewalls, user accounts, permissions, encryption, and domain-based security settings.

---

## 🛡 Defender Antivirus

### Activate / Deactivate
* Controlled through **Windows Security → Virus & threat protection**.
* Can be disabled temporarily for troubleshooting.
* Automatically re-enables unless overridden by Group Policy.

### Update Definitions
* Ensures the latest malware signatures.
* Updated via:
  * Windows Update
  * Manual update
  * Enterprise management tools (Intune, MECM)

---

## 🔥 Firewall

### Activate / Deactivate
* Managed through **Windows Defender Firewall**.
* Separate profiles:
  * Domain
  * Private
  * Public

### Port Security
* Create inbound/outbound rules for specific ports.
* Example: Allow TCP 3389 for RDP.

### Application Security
* Allow/block apps through firewall.
* Useful for troubleshooting connectivity issues.

---

## 👤 Users and Groups

### Local vs. Microsoft Account
* **Local account:** Stored on device; no cloud sync.
* **Microsoft account:** Syncs settings, OneDrive, and Store apps.

### Standard Account
* Limited privileges.
* Cannot install software or change system settings.

### Administrator
* Full system control.
* Can install apps, modify settings, and manage users.

### Guest User
* Highly restricted.
* Disabled by default for security.

### Power User
* Legacy role with elevated permissions.
* Mostly deprecated in modern Windows versions.

---

## 🔐 Log-In OS Options

### Username and Password
* Traditional authentication method.

### PIN
* Windows Hello PIN stored locally.
* More secure than password for device access.

### Fingerprint
* Biometric authentication using Windows Hello.

### Facial Recognition
* Windows Hello face unlock.

### SSO (Single Sign-On)
* One login grants access to multiple services.

### Passwordless / Windows Hello
* Uses biometrics or PIN instead of passwords.

---

## 📂 NTFS vs. Share Permissions

### NTFS Permissions
* Apply to local files and folders.
* More granular (Full Control, Modify, Read & Execute, etc.).

### Share Permissions
* Apply only to network shares.
* Combine with NTFS permissions — **most restrictive wins**.

### File and Folder Attributes
* Read-only  
* Hidden  
* System  
* Archive  

### Inheritance
* Child objects inherit permissions from parent folders.
* Can be disabled for custom permission structures.

---

## ⚙️ Run as Administrator vs. Standard User

* **Run as administrator:** Executes program with elevated privileges.
* Used for:
  * Installing software
  * Running system tools
  * Editing protected files

* **Standard user:** Limited access; safer for daily use.

---

## 🛑 User Account Control (UAC)

* Prompts when apps require elevated privileges.
* Prevents unauthorized changes.
* Configurable levels:
  * Always notify
  * Notify only when apps try to make changes
  * Never notify (not recommended)

---

## 🔐 BitLocker

* Full-disk encryption for Windows.
* Requires:
  * TPM 1.2 or 2.0
  * Pro or Enterprise edition
* Protects data at rest.

---

## 🔐 BitLocker-To-Go

* Encrypts removable drives (USB, external HDD).
* Requires password or smart card to unlock.

---

## 🔐 Encrypting File System (EFS)

* File-level encryption.
* Uses user certificates.
* Only available on NTFS volumes.

---

## 🏢 Active Directory

### Joining Domain
* Allows centralized authentication and policy management.
* Requires domain credentials and network connectivity.

### Assigning Log-In Script
* Automates tasks at log-in:
  * Mapping drives
  * Setting environment variables

### Moving Objects Within Organizational Units (OUs)
* Used to apply different Group Policies.
* Helps organize users and computers.

### Assigning Home Folders
* Network storage assigned per user.
* Often mapped automatically at log-in.

### Applying Group Policy
* Controls:
  * Security settings
  * Software restrictions
  * Desktop configurations

### Selecting Security Groups
* Controls access to resources.
* Examples:
  * Domain Users
  * Domain Admins
  * Security groups for shared folders

### Configuring Folder Redirection
* Redirects user folders (Documents, Desktop) to network storage.
* Improves backup and roaming profile performance.

## ⚡ Key Vocabulary

BitLocker  
: Full-disk encryption protecting data at rest.

UAC  
: Windows feature preventing unauthorized system changes.

NTFS  
: File system supporting permissions, encryption, and compression.

Group Policy  
: Centralized configuration system for domain environments.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: NTFS vs. Share Permissions"
    When both apply, **the most restrictive permission wins**.

!!! danger "Common Pitfall: Disabling Firewall"
    Turning off the firewall should be temporary — many exam scenarios expect you to **create rules**, not disable protection.

!!! tip "Remember: BitLocker Requirements"
    BitLocker requires **TPM** and **Windows Pro/Enterprise**.

!!! warning "Watch Out: UAC Prompts"
    If an app fails due to insufficient privileges, the fix is often **Run as administrator**.

!!! example "Scenario: User Cannot Access Network Folder"
    **Scenario:** A user cannot access a shared folder even though they have NTFS permissions.  
    **Solution:** Check **share permissions** and **security group membership** — share permissions may be more restrictive.
