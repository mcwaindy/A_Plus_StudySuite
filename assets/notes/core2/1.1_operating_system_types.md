## 📌 Overview



Operating systems provide the foundational software layer that manages hardware resources, runs applications, and enables user interaction. Core 2 focuses on identifying major OS types, their intended use cases, filesystem formats, vendor support lifecycles, and cross‑platform compatibility considerations.



---



## 💻 Workstation Operating Systems



### Windows

* **Purpose:** General‑purpose desktop OS for business, gaming, enterprise domains, and productivity.

* **Strengths:** Broad hardware compatibility, Active Directory integration, extensive application support.

* **Common Editions:** Home, Pro, Pro for Workstations, Enterprise.



### Linux

* **Purpose:** Open‑source OS used for servers, security tools, development, and lightweight desktops.

* **Strengths:** Highly customizable, strong CLI tools, wide distribution variety (Ubuntu, Fedora, Debian).

* **Use Cases:** Web servers, penetration testing (Kali), embedded systems.



### macOS

* **Purpose:** Apple’s workstation OS for Mac desktops and laptops.

* **Strengths:** Tight hardware/software integration, strong multimedia workflows, UNIX‑based stability.

* **Limitations:** Only runs on Apple hardware.



### Chrome OS

* **Purpose:** Lightweight cloud‑centric OS built around the Chrome browser.

* **Strengths:** Fast boot, low resource usage, ideal for education and web‑based workflows.

* **Limitations:** Limited offline capability; relies heavily on Google services.



---



## 📱 Mobile Operating Systems



### iPadOS / iOS

* **Purpose:** Apple’s mobile OS for iPhones (iOS) and iPads (iPadOS).

* **Strengths:** Strong security model, curated App Store, seamless ecosystem integration.

* **Restrictions:** Closed platform; apps must be signed and distributed through Apple.



### Android

* **Purpose:** Google’s open mobile OS used across many manufacturers.

* **Strengths:** Highly customizable, wide hardware variety, open app distribution.

* **Variations:** Stock Android, Samsung One UI, Pixel UI.

## 📂 Filesystem Types



### NTFS (New Technology File System)

* **Used By:** Windows.

* **Features:** Permissions, encryption (EFS), compression, large file support, journaling.



### ReFS (Resilient File System)

* **Used By:** Windows Server.

* **Features:** Data integrity checking, auto‑repair, optimized for large storage volumes.



### FAT32 (File Allocation Table 32)

* **Used By:** Legacy systems, removable drives.

* **Limitations:** Max file size **4 GB**, max partition size **2 TB**.



### exFAT (Extensible File Allocation Table)

* **Used By:** Cross‑platform removable storage.

* **Strengths:** Supports large files; ideal for SD cards, USB drives.



### ext4 (Fourth Extended Filesystem)

* **Used By:** Most Linux distributions.

* **Features:** Journaling, large volume support, stable and widely adopted.



### XFS

* **Used By:** Enterprise Linux systems (e.g., RHEL).

* **Strengths:** High‑performance parallel I/O, excellent for large storage arrays.



### APFS (Apple File System)

* **Used By:** macOS, iOS, iPadOS.

* **Features:** Snapshots, strong encryption, optimized for SSDs.

## 🕒 Vendor Life‑Cycle Limitations



### End‑of‑Life (EOL)

* When a vendor stops providing updates, patches, or security fixes.

* **Risks:** Unsupported OS becomes vulnerable to exploits and compliance failures.



### Update Limitations

* Older hardware may not support newer OS versions.

* Mobile devices may stop receiving updates due to chipset or vendor restrictions.

* Enterprise systems may delay updates due to application compatibility concerns.



---



## 🔄 Compatibility Concerns Between Operating Systems



* **File Compatibility:**  

&#x20; * NTFS is read‑only on macOS without third‑party drivers.  

&#x20; * APFS is not natively readable on Windows.  

&#x20; * FAT32/exFAT provide the best cross‑platform compatibility.



* **Application Compatibility:**  

&#x20; * Windows apps do not run natively on macOS or Linux (requires WINE, virtualization, or dual‑boot).  

&#x20; * Mobile apps are platform‑specific (Android APK vs. iOS IPA).



* **Hardware Compatibility:**  

&#x20; * macOS only runs on Apple hardware.  

&#x20; * Linux may require manual driver installation for Wi‑Fi, GPU, or printers.



* **Ecosystem Lock‑In:**  

&#x20; * iOS/macOS rely heavily on Apple services (iCloud, AirDrop).  

&#x20; * Chrome OS depends on Google Workspace and web apps.

## ⚡ Key Vocabulary



Workstation OS  

: Operating system designed for desktops and laptops used in business or personal computing.



Mobile OS  

: Operating system designed for smartphones and tablets with touch‑optimized interfaces.



Filesystem  

: The method an OS uses to store, organize, and retrieve data on storage devices.



End‑of‑Life (EOL)  

: The point at which a vendor stops providing updates or support for an OS.

## ⚡ Exam Tips & Pitfalls



!!! exam "Exam Tip: FAT32 vs. exFAT"

&#x20;   FAT32 cannot store files larger than **4 GB**. If a question mentions copying a **5 GB video file**, the correct answer is **exFAT**.



!!! danger "Common Pitfall: Unsupported OS"

&#x20;   If a scenario mentions an OS no longer receiving updates, the correct action is to **upgrade or replace the OS** due to security risk.



!!! tip "Remember: NTFS Features"

&#x20;   NTFS supports permissions, encryption, compression, and journaling — all common exam keywords.



!!! warning "Watch Out: macOS on Non‑Apple Hardware"

&#x20;   macOS cannot be installed on standard PCs. If a scenario suggests this, it’s incorrect.



!!! example "Scenario: Cross‑Platform File Sharing"

&#x20;   **Scenario:** A user needs to share large video files between Windows, macOS, and Linux systems using a USB drive.  

&#x20;   **Solution:** Format the drive as **exFAT** for maximum compatibility and large file support.
