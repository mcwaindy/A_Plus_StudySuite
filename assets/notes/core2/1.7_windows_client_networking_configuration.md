## 📌 Overview

Windows clients rely on proper network configuration to access shared resources, authenticate to domains, communicate securely, and connect through wired, wireless, or VPN networks. Core 2 requires understanding how to configure network settings, manage firewalls, establish connections, and differentiate between network profiles.

---

## 🏢 Domain Joined vs. Workgroup

### Domain Joined
* Uses **Active Directory** for centralized authentication.
* Ideal for business environments.
* Benefits:
  * Group Policy management
  * Centralized user accounts
  * Access to domain resources (file servers, printers)

### Workgroup
* Peer-to-peer network model.
* No centralized authentication.
* Suitable for home or small office networks.

### Shared Resources
* Domain:
  * Access controlled by AD permissions.
  * Resources include shared folders, printers, and mapped drives.
* Workgroup:
  * Uses local accounts and share permissions.

### Printers
* Domain:
  * Deployed via Group Policy or print servers.
* Workgroup:
  * Shared manually from individual PCs.

### File Servers
* Domain:
  * Centralized storage with NTFS permissions.
* Workgroup:
  * Shared folders on local machines.

### Mapped Drives
* Domain:
  * Often auto-mapped via Group Policy.
* Workgroup:
  * Manually mapped using File Explorer or `net use`.

## 🔥 Local OS Firewall Settings

### Application Restrictions & Exceptions
* Allows or blocks apps through Windows Defender Firewall.
* Used to:
  * Permit remote tools (RDP, SSH)
  * Block unauthorized apps
  * Configure inbound/outbound rules

### Configuration
* Profiles:
  * **Domain**
  * **Private**
  * **Public**
* Each profile has separate rule sets.

## 🌐 Client Network Configuration

### IP Addressing Scheme
* IPv4 or IPv6.
* Includes:
  * IP address
  * Subnet mask
  * Gateway
  * DNS servers

### DNS Settings
* Critical for name resolution.
* Can be:
  * Automatically assigned (DHCP)
  * Manually configured (static)

### Subnet Mask
* Defines network vs. host portion of IP.
* Example: `255.255.255.0` (Class C)

### Gateway
* Router address used to reach external networks.

### Static vs. Dynamic
* **Static:** Manually assigned; used for servers or printers.
* **Dynamic:** Assigned via DHCP; used for most clients.

---

## 🔗 Establish Network Connections

### Virtual Private Network (VPN)
* Creates encrypted tunnel to remote networks.
* Used for:
  * Remote work
  * Secure access to corporate resources

### Wireless (Wi-Fi)
* Connects via SSID and password.
* Supports WPA2/WPA3 security.

### Wired (Ethernet)
* Most stable and fastest connection.
* Auto-configures via DHCP unless set to static.

### Wireless Wide Area Network (WWAN) / Cellular
* Uses SIM card or mobile broadband adapter.
* Ideal for mobile workers or remote locations.

## 🧩 Proxy Settings

* Configured in:
  * **Settings → Network & Internet → Proxy**
  * Or Internet Options (legacy)
* Used to:
  * Route traffic through filtering servers
  * Enforce corporate browsing policies

---

## 🛡 Public vs. Private Network Profiles

### Public Network
* Most restrictive.
* Used in:
  * Airports
  * Hotels
  * Coffee shops
* File sharing disabled.

### Private Network
* Trusted environment.
* Used in:
  * Home networks
  * Office LANs
* Allows device discovery and sharing.

---

## 📁 File Explorer Navigation – Network Paths

* Access shared resources using UNC paths:
  * `*server\share`
  * `*computer\printer`
* Used for:
  * Mapping drives
  * Accessing shared folders
  * Connecting to network printers

---

## 📶 Metered Connections & Limitations

* Marks a network as metered to reduce data usage.
* Effects:
  * Limits background updates
  * Restricts sync operations
  * Reduces bandwidth-heavy tasks

## ⚡ Key Vocabulary

Domain  
: Centralized authentication system using Active Directory.

Workgroup  
: Peer-to-peer network model without centralized control.

Gateway  
: Router address used to reach external networks.

VPN  
: Encrypted connection to remote networks.

Proxy  
: Server that filters or redirects network traffic.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: DNS Issues"
    If a scenario mentions **websites not loading but pinging IP works**, the issue is DNS — check DNS server settings.

!!! danger "Common Pitfall: Wrong Network Profile"
    File sharing will **not** work on a **Public** network. Switch to **Private** to enable discovery.

!!! tip "Remember: Mapped Drives"
    Mapped drives failing often indicate:
    * Wrong credentials  
    * DNS issues  
    * Server offline  
    * Incorrect UNC path  

!!! warning "Watch Out: Static IP Conflicts"
    If two devices share the same static IP, the network will behave unpredictably. Use DHCP unless static is required.

!!! example "Scenario: Remote Worker Cannot Access Company Resources"
    **Scenario:** A user working from home cannot access internal company servers.  
    **Solution:** Verify **VPN connection** is active and authenticated.
