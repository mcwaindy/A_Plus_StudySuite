## 📌 Overview

Web browsers are a primary attack surface for malware, phishing, and data theft. Core 2 requires understanding how to configure secure browser settings, manage extensions, verify trusted downloads, enforce secure connections, and apply privacy controls to protect users in SOHO and enterprise environments.

---

## 📥 Browser Download & Installation

### Trusted Sources
* Download browsers only from:
  * Official vendor sites (Chrome, Firefox, Edge)
  * Managed enterprise portals
* Prevents installation of tampered or malicious versions.

#### Hashing
* Verifies file integrity using:
  * SHA‑256
  * SHA‑1 (legacy)
* Ensures downloaded installers match vendor‑provided hashes.

### Untrusted Sources
* Third-party sites may host:
  * Modified installers
  * Bundled adware/PUPs
  * Malware‑infected versions
* Avoid downloading from:
  * Torrent sites
  * Mirror sites without verification
  * Unknown domains

---

## 🔄 Browser Patching

* Keep browsers updated to:
  * Fix vulnerabilities
  * Improve performance
  * Patch zero‑day exploits
* Most modern browsers auto‑update, but manual checks may be required.

---

## 🧩 Extensions & Plug‑Ins

### Trusted Sources
* Install only from:
  * Official extension stores
  * Verified developers
* Review:
  * Permissions
  * Ratings
  * Update history

### Untrusted Sources
* Risk of:
  * Spyware
  * Adware
  * Credential theft
* Avoid sideloading extensions unless required and verified.

---

## 🔐 Password Managers

* Built-in or third‑party managers store encrypted credentials.
* Benefits:
  * Strong, unique passwords
  * Autofill protection
  * Reduced phishing risk
* Must be secured with strong master password or biometrics.

---

## 🔒 Secure Connections / Sites

### Valid Certificates
* HTTPS ensures:
  * Encryption
  * Authenticity
  * Integrity
* Browsers warn about:
  * Expired certificates
  * Self-signed certificates
  * Mismatched domains

## ⚙️ Browser Settings

### Pop-Up Blocker
* Prevents unwanted ads and malicious pop-ups.
* Can be selectively allowed for trusted sites.

### Clearing Browsing Data
* Removes:
  * Cookies
  * History
  * Saved site data
* Useful for privacy and troubleshooting.

### Clearing Cache
* Fixes:
  * Page loading issues
  * Outdated content
* Helps prevent cached malware scripts from reloading.

### Private-Browsing Mode
* Does not save:
  * History
  * Cookies
  * Form data
* Does **not** hide activity from ISPs or employers.

### Sign-In / Browser Data Synchronization
* Syncs:
  * Bookmarks
  * Passwords
  * Extensions
* Must be secured with MFA and strong account protections.

### Ad Blockers
* Reduce:
  * Malicious ads
  * Tracking
  * Drive-by downloads

### Proxy
* Routes traffic through filtering or security servers.
* Used for:
  * Content filtering
  * Anonymity
  * Corporate policy enforcement

### Secure DNS
* DNS-over-HTTPS (DoH) or DNS-over-TLS (DoT)
* Prevents DNS hijacking and eavesdropping.

---

## 🧰 Browser Feature Management

### Enable/Disable Plug-Ins
* Legacy plug-ins (Flash, Java) are deprecated.
* Disable unused or insecure plug-ins.

### Enable/Disable Extensions
* Remove or disable:
  * Unused extensions
  * Suspicious extensions
  * Extensions requesting excessive permissions

### Enable/Disable Features
* Examples:
  * Password saving
  * Autofill
  * Third-party cookies
  * JavaScript (rarely disabled, but possible)
* Adjust based on security requirements.

---

## ⚡ Key Vocabulary

Secure DNS  
: Encrypted DNS queries preventing interception.

Private Browsing  
: Mode that avoids storing local browsing data.

Hash Verification  
: Confirms downloaded files are unmodified.

Extension Permissions  
: Controls what browser data an extension can access.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: HTTPS"
    If a scenario mentions “secure website access,” the correct answer is **HTTPS with a valid certificate**.

!!! danger "Common Pitfall: Installing Extensions from Unknown Sites"
    Untrusted extensions often contain spyware or adware — always use official stores.

!!! tip "Remember: Secure DNS"
    DoH/DoT protects DNS queries from interception and spoofing.

!!! warning "Watch Out: Browser Sync"
    Syncing passwords without MFA is a major security risk.

!!! example "Scenario: Browser Redirects to Unknown Sites"
    **Scenario:** A user reports constant redirects and pop-ups.  
    **Solution:** Remove suspicious extensions, clear cache, update browser, and enable pop-up blocking.
