## 📌 Overview



Windows provides a wide range of built-in tools for monitoring performance, managing hardware, configuring startup behavior, and administering system settings. Core 2 requires recognizing these tools, understanding their purpose, and selecting the correct tool for a given troubleshooting scenario.



---



## 🧰 Task Manager



Task Manager provides real-time monitoring and control over applications, background processes, and system performance.



### Processes

* Displays running apps and background processes.

* Allows ending tasks, identifying resource hogs, and checking process hierarchy.



### Performance

* Real-time graphs for CPU, memory, disk, network, and GPU usage.

* Useful for diagnosing bottlenecks or hardware stress.



### Services

* Shows Windows services and their running/stopped state.

* Allows starting/stopping services directly.



### Startup

* Controls which applications launch at boot.

* Displays startup impact (Low, Medium, High).



### Users

* Shows logged-in users and their resource usage.

* Allows disconnecting or logging off users in multi-user environments.



---



## 🖥 Microsoft Management Console (MMC) Snap-ins



MMC provides a unified framework for administrative tools. Each snap-in focuses on a specific system component.



### Event Viewer (eventvwr.msc)

* Logs system, security, and application events.

* Essential for diagnosing crashes, failed logins, and hardware errors.



### Disk Management (diskmgmt.msc)

* Manages partitions, volumes, drive letters, and formatting.

* Used for creating, shrinking, extending, or deleting partitions.



### Task Scheduler (taskschd.msc)

* Automates tasks based on triggers (time, startup, event).

* Used for maintenance scripts, backups, or scheduled updates.



### Device Manager (devmgmt.msc)

* Displays hardware devices and drivers.

* Used to update drivers, disable devices, or identify hardware conflicts.



### Certificate Manager (certmgr.msc)

* Manages certificates for encryption, authentication, and secure communications.



### Local Users and Groups (lusrmgr.msc)

* Creates and manages local user accounts and security groups.

* Not available in Windows Home editions.



### Performance Monitor (perfmon.msc)

* Advanced performance tracking with detailed counters.

* Useful for long-term monitoring and diagnosing intermittent issues.



### Group Policy Editor (gpedit.msc)

* Configures system-wide policies for security, software restrictions, and user environment.

* Available only in Pro and Enterprise editions.

## 🧩 Additional Windows Tools



### System Information (msinfo32.exe)

* Displays detailed hardware and software configuration.

* Useful for checking BIOS version, installed RAM, and system model.



### Resource Monitor (resmon.exe)

* Provides granular real-time monitoring of CPU, disk, network, and memory usage.

* More detailed than Task Manager.



### System Configuration (msconfig.exe)

* Controls boot options, services, and startup behavior.

* Used for diagnostic startup or safe boot troubleshooting.



### Disk Cleanup (cleanmgr.exe)

* Removes temporary files, system cache, and old update files.

* Helps free disk space and improve performance.



### Disk Defragmenter (dfrgui.exe)

* Optimizes file placement on HDDs.

* Not needed for SSDs (TRIM handles optimization).



### Registry Editor (regedit.exe)

* Directly edits the Windows registry.

* Powerful but risky — incorrect edits can break the OS.

## ⚡ Key Vocabulary



Task Manager  

: Real-time monitoring tool for processes, performance, and startup apps.



MMC  

: Framework for administrative snap-ins used to manage system components.



Event Viewer  

: Logs system events used for diagnosing errors and security issues.



Registry  

: Hierarchical database storing system and application configuration settings.



Performance Monitor  

: Advanced tool for tracking detailed performance metrics over time.

## ⚡ Exam Tips & Pitfalls



!!! exam "Exam Tip: Task Manager vs. Resource Monitor"

&#x20;   Task Manager gives a **high-level overview**, while Resource Monitor provides **deep, granular details**. If a scenario mentions “per-process disk I/O” or “network TCP connections,” choose **Resource Monitor**.



!!! danger "Common Pitfall: Editing the Registry"

&#x20;   Registry edits are powerful and dangerous. If a scenario mentions registry corruption, the correct action is often **System Restore** or **repair installation**, not manual editing.



!!! tip "Remember: gpedit.msc Availability"

&#x20;   Group Policy Editor is **not available** in Windows Home. If a scenario requires policy changes, the correct edition is **Pro or Enterprise**.



!!! warning "Watch Out: Disk Defrag on SSDs"

&#x20;   SSDs should **not** be defragmented. Windows automatically uses TRIM instead.



!!! example "Scenario: Slow Boot Times"

&#x20;   **Scenario:** A user reports extremely slow startup times.  

&#x20;   **Solution:** Open **Task Manager → Startup** to disable high-impact startup apps.
