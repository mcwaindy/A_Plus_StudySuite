## 📌 Overview

macOS is Apple’s UNIX‑based desktop operating system designed for stability, security, and tight hardware/software integration. Core 2 requires understanding how macOS installs applications, manages system folders, uses built‑in tools, handles backups, and provides unique features such as Spotlight, Mission Control, and Continuity.

---

## 📦 Installation & Uninstallation of Applications

### File Types
* **.dmg (Disk Image)**  
  * Mounted like a virtual disk.  
  * Often contains an app that is dragged into `/Applications`.

* **.pkg (Package Installer)**  
  * Runs an installation wizard.  
  * Used for system-level installs or apps requiring deeper integration.

* **.app**  
  * The application bundle itself.  
  * Typically stored in `/Applications`.

### App Store
* Centralized app distribution platform.
* Handles updates, purchases, and licensing.

### Uninstallation Process
* Most apps are removed by dragging the `.app` file to the Trash.
* Some apps require:
  * Removing support files from `/Library` or `~/Library`
  * Using built-in uninstallers (for complex apps)

## 📁 System Folders

### /Applications
* Stores installed applications.

### /Users
* Contains user home directories.

### /Library
* System-wide support files, fonts, preferences, and frameworks.

### /System
* Core macOS system files; protected by System Integrity Protection (SIP).

### /Users/Library (~/Library)
* User-specific settings, caches, and application support files.

## 👤 Apple ID & Corporate Restrictions

* Apple ID required for:
  * App Store
  * iCloud
  * iMessage
  * FaceTime
* Corporate environments may enforce:
  * Mobile Device Management (MDM)
  * App restrictions
  * Configuration profiles
  * Remote wipe and supervision

## 🛡 Best Practices

### Backups
* **Time Machine** provides automated versioned backups.
* Supports external drives and network storage.

### Antivirus
* macOS includes built-in protections (XProtect), but third-party AV may be required in enterprise environments.

### Updates/Patches
* Regular macOS updates improve security and stability.

### Rapid Security Response (RSR)
* Delivers urgent security patches without full OS updates.

## ⚙️ System Preferences (System Settings in macOS Ventura+)

### Displays
* Resolution, scaling, color profiles, external monitor settings.

### Networks
* Wi-Fi, Ethernet, VPN, proxies, and advanced network configuration.

### Printers & Scanners
* Add/remove printers, manage queues, configure scanning devices.

### Privacy
* App permissions for camera, microphone, location, files, and automation.

### Accessibility
* VoiceOver, Zoom, display contrast, keyboard/mouse accessibility.

### Time Machine
* Backup configuration and restore options.

## 🌟 macOS Features

### Multiple Desktops
* Virtual desktops for organizing workflows.

### Mission Control
* Overview of all open windows, desktops, and full-screen apps.

### Keychain
* Password and certificate management.
* Syncs with iCloud Keychain.

### Spotlight
* System-wide search for apps, files, settings, and web results.

### iCloud
* Cloud services including:
  * **iMessage**
  * **FaceTime**
  * **iCloud Drive**
  * Photos, backups, and sync

### Gestures
* Multi-touch trackpad gestures (Mission Control, App Exposé, pinch-to-zoom).

### Finder
* File management interface.
* Supports tags, views, and quick actions.

### Dock
* Quick access to apps and minimized windows.

### Continuity
* Cross-device features:
  * Handoff
  * Universal Clipboard
  * AirDrop
  * Continuity Camera
  * Calls/messages on Mac

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: App Installation"
    `.dmg` files are **not** installers — they are disk images. The app must be dragged into `/Applications`.

!!! danger "Common Pitfall: Deleting System Files"
    `/System` and `/Library` contain critical files. Removing items here can break macOS.

!!! tip "Remember: FileVault"
    If a scenario mentions **full-disk encryption**, the correct macOS feature is **FileVault**.

!!! warning "Watch Out: Corporate Restrictions"
    MDM profiles can prevent app installation, enforce passwords, or restrict iCloud usage.

!!! example "Scenario: Mac Running Out of Space"
    **Scenario:** A user’s Mac is low on storage and apps are behaving slowly.  
    **Solution:** Use **Disk Utility → First Aid** to check the disk, then review storage in **System Settings → General → Storage**.
