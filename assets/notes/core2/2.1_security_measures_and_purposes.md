## 📌 Overview

Security measures protect people, devices, data, and networks from unauthorized access, theft, and compromise. Core 2 requires understanding physical security controls, physical access mechanisms, and logical security technologies — and knowing when each is appropriate in a given scenario.

---

## 🛡 Physical Security

Physical security prevents unauthorized individuals from entering protected areas or accessing equipment.

### Bollards
* Heavy posts preventing vehicle access.
* Used outside buildings to stop ramming attacks.

### Access Control Vestibule (Mantrap)
* Two-door system controlling entry.
* Prevents tailgating and unauthorized access.

### Badge Reader
* Uses RFID or NFC badges for controlled entry.
* Logs access events.

### Video Surveillance
* CCTV cameras monitor sensitive areas.
* Supports real-time monitoring and forensic review.

### Alarm Systems
* Detect unauthorized entry or environmental hazards.
* Alerts security personnel or triggers automated responses.

### Motion Sensors
* Detect movement in restricted zones.
* Used in alarm systems and automated lighting.

### Door Locks
* Mechanical or electronic locks securing entry points.
* Includes keypad locks, magnetic locks, and smart locks.

### Equipment Locks
* Physical locks for servers, laptops, and racks.
* Prevent theft or tampering.

### Security Guards
* Human presence providing deterrence and response.
* Can verify identity and monitor access.

### Fences
* Perimeter protection preventing unauthorized entry.
* Often combined with lighting and surveillance.

---

## 🚪 Physical Access Security

Controls that verify identity before granting access to buildings or secure areas.

### Key Fobs
* Wireless tokens using RFID/NFC.
* Used for building entry and secure rooms.

### Smart Cards
* Embedded chip for authentication.
* Used for badge readers, workstation login, and secure facilities.

### Mobile Digital Key
* Smartphone-based access credential.
* Uses NFC, Bluetooth, or QR codes.

### Keys
* Traditional mechanical access control.
* Still common for low-security areas.

### Biometrics
Biometric authentication uses unique physical traits.

* **Retina Scanner** — analyzes blood vessel patterns in the eye.  
* **Fingerprint Scanner** — common on laptops and mobile devices.  
* **Palm Print Scanner** — used in high-security environments.  
* **Facial Recognition Technology (FRT)** — used for device unlock and building access.  
* **Voice Recognition Technology** — used for call center authentication.

### Lighting
* Enhances visibility and deters unauthorized activity.
* Critical for perimeter security.

### Magnetometers
* Metal detectors used at secure entrances.
* Detect weapons or prohibited items.

## 🔐 Logical Security

Logical controls protect data, systems, and user accounts through software-based mechanisms.

### Principle of Least Privilege
* Users receive only the access necessary to perform their job.
* Reduces risk of misuse or compromise.

### Zero Trust Model
* “Never trust, always verify.”
* Continuous authentication and authorization.

### Access Control Lists (ACLs)
* Define permissions for files, folders, and network resources.

### Multifactor Authentication (MFA)
Requires two or more authentication factors:

* **Email**
* **Hardware token**
* **Authenticator application**
* **SMS**
* **Voice call**
* **Time-based one-time password (TOTP)**
* **One-time password/passcode (OTP)**

### Security Assertions Markup Language (SAML)
* XML-based authentication standard.
* Used for web-based SSO.

### Single Sign-On (SSO)
* One login grants access to multiple systems.
* Reduces password fatigue and improves security.

### Just-in-Time Access
* Temporary elevated access granted only when needed.
* Often used with:
  * **Privileged Access Management (PAM)**

### Mobile Device Management (MDM)
* Controls mobile device security:
  * Remote wipe
  * App restrictions
  * Encryption enforcement
  * Compliance checks

### Data Loss Prevention (DLP)
* Prevents unauthorized data transfer or leakage.
* Monitors email, cloud storage, USB usage.

### Identity Access Management (IAM)
* Centralized identity control:
  * Authentication
  * Authorization
  * Role-based access

### Directory Services
* Systems managing user accounts and permissions.
* Examples:
  * Active Directory
  * LDAP directories

## ⚡ Key Vocabulary

Mantrap  
: Two-door access system preventing tailgating.

Zero Trust  
: Security model requiring continuous verification.

ACL  
: Permissions list defining access to resources.

MDM  
: Toolset for managing and securing mobile devices.

DLP  
: Technology preventing unauthorized data exfiltration.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Physical vs. Logical"
    If a scenario mentions **building access**, choose physical controls.  
    If it mentions **data access**, choose logical controls.

!!! danger "Common Pitfall: Overprivileged Accounts"
    Excessive permissions violate the **principle of least privilege** and increase risk.

!!! tip "Remember: MFA Types"
    Hardware tokens and authenticator apps are more secure than SMS or email codes.

!!! warning "Watch Out: Tailgating"
    Tailgating is prevented by **mantraps**, not badge readers alone.

!!! example "Scenario: Preventing Data Leakage"
    **Scenario:** A company wants to stop employees from emailing sensitive data externally.  
    **Solution:** Implement **DLP** policies to monitor and block unauthorized transfers.
