## 📌 Overview



Operating system installations and upgrades require understanding boot methods, installation types, partitioning schemes, drive formats, and compatibility considerations. Core 2 emphasizes performing installations in varied environments, ensuring proper preparation, minimizing downtime, and maintaining data integrity.



---



## 🔧 Boot Methods



### Universal Serial Bus (USB)

* Most common modern installation method.

* Supports bootable installers created with tools like Media Creation Tool or dd.

* Ideal for systems without optical drives.



### Network Boot (PXE)

* Uses Preboot Execution Environment (PXE) to boot from a network server.

* Common in enterprise environments for mass deployments.

* Requires DHCP and TFTP services.



### Solid-State / Flash Drives

* Similar to USB boot but may refer to internal SSDs containing installation media.

* Fast read speeds improve installation time.



### Internet-Based Boot

* Cloud recovery or online installation (e.g., macOS Internet Recovery).

* Requires stable network connection.



### External / Hot-Swappable Drive

* Booting from external HDD/SSD via USB or Thunderbolt.

* Useful for diagnostics or portable OS environments.



### Internal Hard Drive (Partition)

* Systems may include a recovery or installation partition.

* Allows reinstalling OS without external media.



### Multiboot

* Multiple OSs installed on separate partitions.

* Requires careful bootloader configuration (GRUB, Windows Boot Manager).



---



## 🛠 Types of Installations



### Clean Install

* Wipes existing data and installs a fresh OS.

* Best for malware removal, major version changes, or corrupted systems.



### Upgrade

* Moves from an older OS version to a newer one while preserving data and apps.

* Requires compatibility checks.



### Image Deployment

* Uses preconfigured OS images (WIM, ISO, or custom enterprise images).

* Ideal for standardized workstation setups.



### Remote Network Installation

* OS installed over the network using deployment servers.

* Common in enterprise IT environments.



### Zero-Touch Deployment

* Fully automated installation with no user interaction.

* Uses tools like Microsoft Endpoint Configuration Manager (MECM).



### Recovery Partition

* Built-in partition containing OS recovery tools.

* Allows factory reset or repair without external media.



### Repair Installation

* Reinstalls OS components while preserving user data.

* Windows example: “In-place upgrade repair.”



### Other Considerations

* **Third-party drivers** may be required for RAID controllers, NVMe drives, or specialized hardware.



---



## 📐 Partitioning



### GUID Partition Table (GPT)

* Modern standard for UEFI systems.

* Supports large drives (>2 TB) and up to 128 partitions.

* More robust and includes redundancy.



### Master Boot Record (MBR)

* Legacy BIOS partitioning scheme.

* Supports up to 4 primary partitions and drives up to 2 TB.

* Less resilient to corruption.



---



## 💾 Drive Format



* **NTFS** – Windows default; supports permissions, encryption, large files.

* **exFAT** – Best for cross-platform removable storage.

* **APFS** – macOS/iOS default; optimized for SSDs.

* **ext4/XFS** – Common Linux filesystems.

* Drive format must match OS requirements and intended use case.



---



## 🔄 Upgrade Considerations



### Backup Files & User Preferences

* Always back up user data before upgrades.

* Use cloud backup, external drives, or enterprise backup solutions.



### Application & Driver Support / Backward Compatibility

* Older apps may not run on newer OS versions.

* Drivers may need updating or replacement.



### Hardware Compatibility

* Minimum CPU, RAM, storage, and firmware requirements must be met.

* Some older systems cannot upgrade due to unsupported chipsets.



---



## 🆕 Feature Updates & Product Life Cycle



### Feature Updates

* OS vendors release periodic updates adding functionality and security improvements.

* Windows: Semi-annual feature updates.

* macOS/iOS/Android: Annual major releases.



### Product Life Cycle

* Includes mainstream support, extended support, and end-of-life (EOL).

* EOL systems no longer receive security patches — upgrade recommended.

## ⚡ Key Vocabulary



Boot Method  

: The technique used to load installation media or recovery tools.



Clean Install  

: A fresh OS installation that removes all existing data.



Image Deployment  

: Installing an OS using a preconfigured system image.



GPT  

: Modern partitioning scheme used with UEFI firmware.



Zero-Touch Deployment  

: Automated OS installation requiring no user interaction.

## ⚡ Exam Tips & Pitfalls



!!! exam "Exam Tip: GPT vs. MBR"

&#x20;   GPT is required for UEFI booting and supports drives larger than 2 TB. If the scenario mentions a 4 TB drive, GPT is the correct answer.



!!! danger "Common Pitfall: Skipping Backups"

&#x20;   Upgrades can fail. Always back up user data before performing any OS upgrade.



!!! tip "Remember: Zero-Touch Deployment"

&#x20;   Zero-touch means **fully automated** — no technician interaction.



!!! warning "Watch Out: Driver Requirements"

&#x20;   RAID or NVMe installations may require loading third-party drivers during setup.



!!! example "Scenario: Enterprise Deployment"

&#x20;   **Scenario:** An organization needs to deploy 200 identical Windows systems quickly.  

&#x20;   **Solution:** Use **image deployment** or **PXE-based zero-touch installation** for efficiency and consistency.
