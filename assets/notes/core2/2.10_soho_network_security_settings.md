## 📌 Overview

Small office/home office (SOHO) networks rely on consumer‑grade routers and wireless access points, which require proper configuration to ensure security. Core 2 requires understanding router settings, wireless security controls, firewall configuration, and best practices for securing both wired and wireless environments.

---

## 🛠 Router Settings

### Change Default Passwords
* Default admin passwords are widely known.
* Replace with strong, unique credentials.
* Prevents unauthorized access to router configuration.

### IP Filtering
* Restricts access based on IP address.
* Can block:
  * Malicious IPs
  * Unauthorized internal devices
* Useful for basic access control.

### Firmware Updates
* Fix vulnerabilities and improve stability.
* Should be applied regularly.
* Prevents exploitation of outdated router software.

### Content Filtering
* Blocks:
  * Malicious websites
  * Adult content
  * Phishing domains
* Often integrated into parental controls or security dashboards.

### Physical Placement / Secure Locations
* Place router in a central, secure area.
* Avoid:
  * Exterior walls (reduces Wi-Fi leakage)
  * Public access areas
* Prevents tampering and improves signal coverage.

### Universal Plug and Play (UPnP)
* Automatically opens ports for applications.
* **Security risk** — malware can exploit it.
* Best practice: **Disable UPnP** unless absolutely required.

### Screened Subnet (DMZ)
* Isolates public-facing devices from internal network.
* Useful for:
  * Web servers
  * IoT devices
* Prevents lateral movement into secure systems.

### Configure Secure Management Access
* Disable remote administration unless needed.
* Use:
  * HTTPS instead of HTTP
  * Strong passwords
  * IP restrictions
* Prevents unauthorized configuration changes.

## 📡 Wireless-Specific Security

### Changing the SSID
* Rename default SSID to avoid identifying device brand/model.
* Avoid personal information in SSID names.

### Disabling SSID Broadcast
* Hides network name from casual scanning.
* Not a strong security measure — SSID still detectable with tools.
* Useful for reducing visibility.

### Encryption Settings
* Use:
  * **WPA3** (best)
  * **WPA2‑AES** (fallback)
* Avoid:
  * WEP
  * WPA‑TKIP
* Strong encryption prevents unauthorized access.

### Configuring Guest Access
* Separate network for visitors.
* Prevents access to internal devices.
* Often bandwidth‑limited and isolated.

---

## 🔥 Firewall Settings

### Disabling Unused Ports
* Close unnecessary ports to reduce attack surface.
* Prevents unauthorized inbound connections.

### Port Forwarding / Mapping
* Allows external access to internal services.
* Examples:
  * Gaming servers
  * Remote access tools
* Must be configured carefully:
  * Use strong authentication
  * Avoid exposing sensitive services
  * Document all forwarded ports

## ⚡ Key Vocabulary

UPnP  
: Automatic port‑opening feature; convenient but risky.

DMZ  
: Screened subnet isolating public-facing devices.

SSID  
: Wireless network name broadcast by access points.

Port Forwarding  
: Routing external traffic to internal devices.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Encryption"
    If a scenario mentions “strong wireless security,” the correct answer is **WPA3** or **WPA2‑AES** — never TKIP or WEP.

!!! danger "Common Pitfall: Leaving UPnP Enabled"
    UPnP is a major SOHO vulnerability. Disable it unless absolutely required.

!!! tip "Remember: Guest Networks"
    Guest networks should be **isolated** from internal LAN resources.

!!! warning "Watch Out: Default Router Credentials"
    Attackers often scan for routers using default admin passwords — changing them is the first hardening step.

!!! example "Scenario: Unauthorized Wi-Fi Access"
    **Scenario:** A neighbor is connecting to a user’s Wi-Fi network.  
    **Solution:** Change SSID, enable WPA3/WPA2‑AES, update password, and disable WPS/UPnP.
