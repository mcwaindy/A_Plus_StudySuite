## 📌 Overview

Application installation requires verifying system compatibility, meeting hardware requirements, selecting appropriate distribution methods, and understanding the operational impact of new software. Core 2 emphasizes evaluating system readiness, choosing the correct installation source, and anticipating how new applications affect devices, networks, and business workflows.

---

## 🖥 System Requirements for Applications

### 32-bit vs. 64-bit Dependent Application Requirements
* **32-bit apps** run on both 32-bit and 64-bit OSs.
* **64-bit apps** require a 64-bit OS and compatible CPU.
* 64-bit applications can access more RAM and perform better on modern systems.

### Dedicated vs. Integrated Graphics Card
* **Dedicated GPU:** Required for high-end gaming, video editing, CAD, and 3D rendering.
* **Integrated GPU:** Sufficient for basic productivity apps and lightweight workloads.

### Video RAM (VRAM) Requirements
* Applications like video editors, 3D modeling tools, and games require specific VRAM amounts.
* Example: A video editing suite may require **4–8 GB VRAM**.

### RAM Requirements
* Minimum RAM varies by application.
* Heavy workloads (VMs, editing software) may require **16 GB+**.
* Insufficient RAM causes slowdowns or installation failure.

### CPU Requirements
* Applications may require:
  * Specific clock speeds
  * Multi-core processors
  * Instruction set support (e.g., AVX)
* CPU bottlenecks can prevent installation or degrade performance.

### External Hardware Tokens
* Some applications require:
  * USB dongles
  * Smart cards
  * Hardware authentication keys (e.g., YubiKey)
* Common in enterprise licensing and secure environments.

### Storage Requirements
* Applications may require:
  * Minimum free disk space
  * SSD for optimal performance
  * Additional space for caches or project files

### Application to OS Compatibility
* Applications must match OS version and architecture.
* Example:
  * macOS apps may require a specific macOS release.
  * Windows apps may require .NET Framework or Visual C++ redistributables.

## 📦 Distribution Methods

### Physical Media vs. Mountable ISO File
* **Physical media:** DVD, USB installer.
* **ISO files:** Mounted virtually; common for enterprise deployments.

### Downloadable Package
* Most common method.
* Includes:
  * .exe (Windows)
  * .msi (Windows installer)
  * .pkg / .dmg (macOS)
  * .deb / .rpm (Linux)

### Image Deployment
* Used for mass installations.
* Deploys preconfigured system images with applications included.
* Ideal for enterprise environments.

## 📊 Impact Considerations for New Applications

### Device Impact
* Increased CPU, RAM, and storage usage.
* Possible driver or compatibility conflicts.
* May require firmware or OS updates.

### Network Impact
* Applications may:
  * Sync large amounts of data
  * Consume bandwidth
  * Require firewall exceptions
  * Introduce new network protocols

### Operational Impact
* Changes to workflows or user training.
* Potential downtime during installation.
* Compatibility with existing tools.

### Business Impact
* Licensing costs.
* Security considerations.
* Compliance requirements.
* Productivity changes (positive or negative).

## ⚡ Key Vocabulary

ISO File  
: A disk image used for virtual or physical installation media.

VRAM  
: Memory dedicated to graphics processing.

Image Deployment  
: Installing applications via preconfigured system images.

Hardware Token  
: Physical device used for authentication or licensing.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: 64-bit Requirements"
    If an application requires more than **4 GB RAM**, it must be **64-bit** — and so must the OS.

!!! danger "Common Pitfall: Ignoring GPU Requirements"
    Applications like CAD or video editing will fail or perform poorly on integrated graphics.

!!! tip "Remember: Storage Requirements"
    Installers often require **extra temporary space** beyond the app’s final size.

!!! warning "Watch Out: OS Compatibility"
    If a scenario mentions installation failure on macOS or Linux, check whether the package format matches the OS.

!!! example "Scenario: Enterprise Deployment"
    **Scenario:** A company needs to install a new CRM application on 200 machines.  
    **Solution:** Use **image deployment** or automated installation scripts to ensure consistency and reduce manual labor.
