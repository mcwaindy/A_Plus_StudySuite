## 📌 Overview

Windows provides numerous configuration panels and settings categories that allow technicians to manage system behavior, security, hardware, personalization, and user preferences. Core 2 requires identifying the correct settings area for a given scenario and understanding what each tool controls.

---

## 🌐 Internet Options

* Found in **Control Panel**.
* Manages:
  * Browser security zones
  * Privacy settings (cookies, pop-ups)
  * Content filters
  * Certificates
  * Proxy configuration
* Primarily affects Internet Explorer and legacy components still used by Windows.

---

## 🖨 Devices and Printers

* Displays connected printers, scanners, and peripherals.
* Used to:
  * Set default printer
  * Manage print queues
  * Troubleshoot device connectivity
  * Adjust device-specific settings

---

## 📦 Programs and Features

* Used to install, uninstall, or modify applications.
* Also manages:
  * Windows features (e.g., .NET Framework)
  * Optional components
* Supports repair installs for certain applications.

---

## 🌐 Network and Sharing Center

* Legacy networking control panel.
* Used to:
  * View active network connections
  * Configure network adapters
  * Change advanced sharing settings
  * Manage network profiles (Private vs. Public)

---

## 💻 System

* Provides system-level information and configuration.
* Includes:
  * Device specifications
  * Windows edition and activation
  * Performance settings
  * Remote Desktop configuration
  * Advanced system settings (environment variables, virtual memory)

---

## 🔥 Windows Defender Firewall

* Controls inbound/outbound traffic rules.
* Used to:
  * Allow/block apps

  * Configure domain/private/public profiles

## 📁 File Explorer Options

### View Hidden Files
* Enables visibility of hidden system files.

### Hide Extensions
* Toggles file extension visibility (recommended OFF for troubleshooting).

### General Options
* Controls browsing behavior, privacy, and folder opening style.

### View Options
* Controls folder view settings, thumbnails, and advanced display options.

---

## 🔌 Power Options

### Hibernate
* Saves system state to disk; uses zero power.

### Power Plans
* Balanced, High Performance, Power Saver.
* Controls CPU scaling, display timeout, and sleep behavior.

### Sleep / Suspend
* Saves system state to RAM; uses minimal power.

### Standby
* Legacy term for sleep mode.

### Choose What Closing the Lid Does
* Configures lid-close actions (sleep, hibernate, shutdown, do nothing).

### Turn On Fast Startup
* Hybrid boot combining hibernation + cold boot for faster startup.

### USB Selective Suspend
* Saves power by disabling idle USB ports.

## ⚡ Key Vocabulary

: Legacy configuration interface for system settings.

Settings App  
: Modern interface introduced in Windows 10/11 for user-friendly configuration.

Fast Startup  
: Hybrid boot mode combining hibernation and cold boot.

Indexing  
: Process that speeds up file searches by cataloging file metadata.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: File Extensions"
    If a scenario mentions difficulty identifying file types, the fix is **File Explorer Options → View → Uncheck “Hide extensions for known file types.”**

!!! danger "Common Pitfall: Fast Startup"
    Fast Startup can prevent full shutdown. If troubleshooting drivers or hardware, perform a **full shutdown** using `shutdown /s`.

!!! tip "Remember: Device Manager"
    If a scenario mentions **driver issues**, **unknown devices**, or **hardware conflicts**, Device Manager is the correct tool.

!!! warning "Watch Out: Indexing Problems"
    Slow or incorrect search results often require **Indexing Options → Rebuild Index**.

!!! example "Scenario: Laptop Sleeps When Lid Closes"
    **Scenario:** A user’s laptop keeps sleeping during presentations when they close the lid.  
    **Solution:** Go to **Power Options → Choose what closing the lid does → Set to “Do nothing.”**
