## 📌 Overview

Linux is a flexible, open-source operating system used across desktops, servers, and embedded systems. Core 2 requires familiarity with common Linux commands, configuration files, package managers, OS components, and administrative tools used in troubleshooting and system management.

---

## 📁 File Management Commands

### ls
* Lists directory contents.
* Common flags:
  * `-l` (long format)
  * `-a` (show hidden files)

### pwd
* Prints the current working directory.

### mv
* Moves or renames files and directories.

### cp
* Copies files or directories.
* Use `-r` for recursive directory copy.

### rm
* Removes files or directories.
* Use caution — `rm -r` deletes recursively.

### chmod
* Changes file permissions.
* Supports symbolic (e.g., `u+x`) or numeric (e.g., `755`) modes.

### chown
* Changes file owner and group.
* Example: `chown user:group file.txt`

### grep
* Searches for patterns in files.
* Supports regex and multiple flags.

### find
* Locates files based on name, size, type, or other attributes.

---

## 💽 Filesystem Management

### fsck
* Checks and repairs filesystem integrity.
* Typically run on unmounted filesystems.

### mount
* Attaches a filesystem to a directory.
* Example: `mount /dev/sdb1 /mnt`

---

## 🔐 Administrative Commands

### su
* Switches to another user account.
* `su -` opens a login shell.

### sudo
* Executes commands with elevated privileges.
* Preferred over su for security auditing.

---

## 📦 Package Management

### apt (Debian/Ubuntu)
* Installs, updates, and removes packages.
* Examples:
  * `apt update`
  * `apt install firefox`

### dnf (Fedora/RHEL)
* Modern package manager replacing yum.
* Example: `dnf install nano`

---

## 🌐 Network Commands

### ip
* Displays and configures network interfaces.
* Examples:
  * `ip a` — show addresses
  * `ip r` — show routes

### ping
* Tests connectivity to a host.

### curl
* Transfers data from URLs.
* Useful for API testing and downloads.

### dig
* DNS lookup tool.
* More detailed than nslookup.

### traceroute
* Shows the path packets take to a destination.

---

## 🧾 Informational Commands

### man
* Displays manual pages for commands.

### cat
* Prints file contents to the terminal.

### top
* Real-time process and resource monitor.

### ps
* Lists running processes.
* Example: `ps aux`

### du
* Shows disk usage of files/directories.

### df
* Displays filesystem space usage.

---

## ✏️ Text Editors

### nano
* Simple terminal-based text editor.
* Ideal for beginners and quick edits.

---

## 📂 Common Configuration Files

### /etc/passwd
* Stores user account information.

### /etc/shadow
* Stores hashed passwords and expiration data.

### /etc/hosts
* Local hostname-to-IP mappings.

### /etc/fstab
* Defines filesystems mounted at boot.

### /etc/resolv.conf
* DNS resolver configuration.

---

## 🧩 OS Components

### systemd
* Init system and service manager.
* Controls:
  * Boot process
  * Services
  * Logging (via journalctl)

### kernel
* Core of the OS.
* Manages hardware, memory, processes, and drivers.

### bootloader
* Loads the kernel at startup.
* Common bootloaders:
  * GRUB
  * systemd-boot

---

## 🔐 Root Account

* Superuser with full system privileges.
* Accessed via:
  * `su`
  * `sudo`
* Best practice: avoid logging in directly as root.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: DNS Troubleshooting"
    Use **dig** for detailed DNS lookups. If a scenario mentions “querying DNS records,” dig is the correct tool.

!!! danger "Common Pitfall: rm -r"
    `rm -r` deletes directories recursively. If a scenario mentions accidental data loss, this may be the cause.

!!! tip "Remember: sudo vs. su"
    **sudo** runs a single command with elevated privileges.  
    **su** switches to another user entirely.

!!! warning "Watch Out: Editing /etc/fstab"
    Incorrect entries can prevent the system from booting.

!!! example "Scenario: Network Interface Not Showing"
    **Scenario:** A user cannot see their network interface.  
    **Solution:** Run `ip a` to verify interface status, then check systemd services or drivers.
