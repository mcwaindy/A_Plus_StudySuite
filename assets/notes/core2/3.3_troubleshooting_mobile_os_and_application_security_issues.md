## 📌 Overview

Mobile security issues often arise from unauthorized apps, unsafe configuration changes, compromised devices, or malicious behavior. Core 2 requires identifying security‑related symptoms, determining whether the device is compromised, and applying the correct remediation steps.

---

## 🔐 Security Concerns

### Application Source / Unofficial Application Stores
* Installing apps from:
  * Third‑party stores
  * Unknown APK sites
  * Sideloaded packages  
* Risks:
  * Malware
  * Spyware
  * Data theft
  * Hidden permissions

### Developer Mode
* Enables:
  * USB debugging
  * Sideloading apps
  * Advanced system access  
* Risks:
  * Increased attack surface
  * Easier installation of malicious apps

### Root Access / Jailbreak
* Removes OS security restrictions.
* Allows full system access.
* Risks:
  * Malware with elevated privileges
  * Disabled sandboxing
  * Broken security updates
  * Unsupported OS behavior

### Unauthorized / Malicious Application
* Installed without user knowledge.
* May hide in:
  * Fake apps
  * Cloned apps
  * Background services

#### Application Spoofing
* Malicious app disguised as a legitimate one.
* Often mimics:
  * Banking apps
  * Social media apps
  * System utilities

## ⚠️ Common Symptoms of Mobile Security Issues

### High Network Traffic
**Causes:**  
* Malware sending data externally  
* Spyware uploading logs  
* Cryptominers communicating with servers  

**Fixes:**  
* Check data usage  
* Remove suspicious apps  
* Reset network settings  

---

### Degraded Response Time
**Causes:**  
* Malware running background tasks  
* Rogue apps consuming CPU  
* Excessive ads or trackers  

**Fixes:**  
* Review battery/CPU usage  
* Remove unknown apps  
* Run mobile anti-malware  

---

### Data-Usage Limit Notification
**Causes:**  
* Malware exfiltrating data  
* Background downloads  
* Unauthorized cloud sync  

**Fixes:**  
* Inspect per‑app data usage  
* Disable background data  
* Remove suspicious apps  

---

### Limited Internet Connectivity
**Causes:**  
* Malware modifying DNS  
* VPN hijacking  
* Rogue configuration profiles  

**Fixes:**  
* Reset network settings  
* Remove unknown profiles  
* Disable malicious VPN apps  

---

### No Internet Connectivity
**Causes:**  
* Malicious apps blocking traffic  
* Corrupt network stack  
* OS compromise  

**Fixes:**  
* Restart device  
* Reset network settings  
* Boot into safe mode (Android)  
* Remove malicious apps  

---

### High Number of Ads
**Causes:**  
* Adware  
* Malicious browser extensions  
* Compromised apps  

**Fixes:**  
* Remove adware apps  
* Clear browser data  
* Disable suspicious extensions  

---

### Fake Security Warnings
**Causes:**  
* Scareware  
* Malicious pop-ups  
* Browser hijacking  

**Fixes:**  
* Close browser  
* Clear cache  
* Remove rogue apps  
* Disable notifications from unknown apps  

---

### Unexpected Application Behavior
**Causes:**  
* Malware modifying app permissions  
* Corrupt or spoofed apps  
* Unauthorized background activity  

**Fixes:**  
* Review app permissions  
* Reinstall legitimate apps  
* Remove unknown apps  

---

### Leaked Personal Files / Data
**Causes:**  
* Spyware  
* Unauthorized cloud sync  
* Compromised accounts  
* Root/jailbreak vulnerabilities  

**Fixes:**  
* Change passwords  
* Enable MFA  
* Remove malicious apps  
* Review cloud sync settings  
* Factory reset if necessary  

---

## ⚡ Key Vocabulary

Application Spoofing  
: Malicious app disguised as a legitimate one.

Scareware  
: Fake warnings designed to trick users into installing malware.

Developer Mode  
: Advanced mode enabling debugging and sideloading.

Root/Jailbreak  
: Removing OS restrictions, increasing security risk.

---

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Root/Jailbreak"
    If a scenario mentions **unexpected behavior + disabled security features**, suspect a **rooted or jailbroken device**.

!!! danger "Common Pitfall: Ignoring App Sources"
    Many mobile compromises come from **unofficial stores** or sideloaded APKs.

!!! tip "Remember: High Data Usage"
    Sudden spikes in data usage often indicate **spyware or malware exfiltrating data**.

!!! warning "Watch Out: Fake Security Alerts"
    Real OS warnings appear in consistent system UI — pop-up ads or browser alerts are **not legitimate**.

!!! example "Scenario: Device Shows Constant Ads"
    **Scenario:** A user reports nonstop ads even when no apps are open.  
    **Solution:** Remove adware apps, clear browser data, disable suspicious extensions, and check for unauthorized profiles.
