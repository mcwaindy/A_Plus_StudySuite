## 📌 Overview

Storage devices provide persistent non-volatile data retention across computer systems. Servicing and configuring storage requires understanding mechanical Hard Disk Drives (HDDs), Solid-State Drives (SSDs), communication interfaces (SATA, NVMe, PCIe), form factors, removable media, and Redundant Array of Independent Disks (RAID) configurations.

---

## 💾 Mass Storage Technologies & Form Factors

### Hard Disk Drives (HDDs)
Mechanical magnetic storage utilizing spinning platters and read/write heads.
* **Rotational Speeds:** Measured in Revolutions Per Minute (RPM). Standard consumer drives run at **5,400 RPM** or **7,200 RPM**; high-performance enterprise drives operate at **10,000 RPM** or **15,000 RPM**.
* **Form Factors:**
  * **3.5-inch:** Standard size for desktop PCs and enterprise storage arrays.
  * **2.5-inch:** Compact size designed for laptops and small-form-factor systems.

### Solid-State Drives (SSDs)
Non-mechanical flash storage utilizing NAND flash memory chips. Offers significantly faster read/write speeds, lower latency, zero noise, and high shock resistance compared to mechanical HDDs.

### Storage Communication Interfaces & Bus Protocols
* **SATA (Serial ATA):** Uses the legacy AHCI protocol over SATA data cables (SATA 3.0 max bandwidth: 6 Gbps / ~600 MB/s). Available in 2.5-inch drives and mSATA/M.2 SATA cards.
* **NVMe (Non-Volatile Memory Express):** High-speed protocol designed specifically for flash storage. Communicates directly over the **PCIe bus**, bypassing AHCI limitations to achieve multi-gigabyte-per-second transfer speeds.
* **PCIe Cards:** High-capacity SSDs mounted directly onto PCIe expansion cards for maximum throughput.

### SSD Form Factors
* **2.5-inch SATA SSD:** Standard drop-in replacement for mechanical laptop/desktop drives.
* **mSATA:** Compact legacy SSD card used in older ultra-thin laptops.
* **M.2 SSD:** Modern compact module (~22mm wide) inserted directly into motherboard M.2 slots. Supports both SATA and NVMe protocols. Common length size is **2280** (22mm x 80mm).

## 💿 Removable & Optical Storage

* **USB Flash Drives:** Portable thumb drives utilizing flash memory over USB interfaces.
* **Memory Cards:** Compact flash storage cards (MicroSD, SD) used in cameras, mobile devices, and handheld consoles.
* **Optical Drives:** Uses laser light to read/write data on optical discs:
  * **CD-ROM / CD-RW:** Capacity ~$700\text{ MB}$.
  * **DVD-ROM / DVD-RW:** Single-layer capacity $4.7\text{ GB}$; Dual-layer capacity $8.5\text{ GB}$.
  * **Blu-ray (BD-ROM / BD-RE):** Single-layer capacity $25\text{ GB}$; Dual-layer capacity $50\text{ GB}$.

## 🛡️ RAID Configurations (Redundant Array of Independent Disks)

RAID combines multiple physical storage drives into a single logical volume to provide data redundancy, performance improvement, or a combination of both.

| RAID Level | Minimum Drives | Data Distribution Method | Fault Tolerance / Disk Failures | Key Feature / Advantage |
| :--- | :--- | :--- | :--- | :--- |
| **RAID 0** | 2 drives | **Striping** | **Zero** (1 drive failure destroys all data) | Maximum performance; no redundancy overhead |
| **RAID 1** | 2 drives | **Mirroring** | Up to **1 drive failure** | $100\%$ data redundancy; exact duplicate copy |
| **RAID 5** | 3 drives | **Striping with Distributed Parity** | Up to **1 drive failure** | Efficient balance of performance, redundancy, and capacity |
| **RAID 10 (1+0)** | 4 drives | **Striped Sets of Mirrored Pairs** | Up to **1 drive per pair** (max 2) | High performance + high fault tolerance |

## ⚡ Key Vocabulary

NVMe
: Non-Volatile Memory Express. An open host controller interface protocol optimized for SSDs running directly over PCIe lanes.

RAID
: Redundant Array of Independent Disks. Storage technology combining multiple physical drives into a single logical unit for performance or data safety.

Parity Data
: Redundant mathematical data calculated in RAID 5 used to rebuild lost data if a drive fails.

M.2 2280
: The standard M.2 SSD form factor measuring 22mm wide by 80mm long.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: RAID Minimum Drives & Tolerance"
    CompTIA heavily tests drive counts and fault tolerance:
    * **RAID 0:** Min **2** drives | **0** failures tolerated (Speed only)
    * **RAID 1:** Min **2** drives | **1** failure tolerated (Mirroring)
    * **RAID 5:** Min **3** drives | **1** failure tolerated (Distributed Parity)
    * **RAID 10:** Min **4** drives | **1** failure per mirrored set tolerated

!!! danger "Common Pitfall: NVMe vs. SATA M.2 Compatibility"
    Not all M.2 slots support NVMe! Placing an M.2 NVMe drive into an M.2 slot keyed or routed exclusively for SATA will result in the drive not being detected by the motherboard BIOS/UEFI.

!!! tip "Remember: RAID 0 Has Zero Redundancy"
    The "0" in **RAID 0** stands for how much data redundancy it provides: **Zero!** If a single drive in a RAID 0 array fails, all data across the entire volume is permanently lost.

!!! warning "Watch Out: HDD RPM Performance"
    Enterprise servers rely on **10,000 RPM** or **15,000 RPM** drives for lower mechanical seek times, whereas budget laptops and backup external storage rely on slower, quieter **5,400 RPM** drives.

!!! example "Scenario: High-Speed Web Server with Storage Redundancy"
    **Scenario:** A company needs to configure a database server that requires maximum read/write performance while maintaining fault tolerance against physical drive failures.
    
    **Solution:** Install a **RAID 10** array using four high-speed **NVMe M.2 SSDs**. RAID 10 provides striping performance with mirrored fault tolerance.
