## 📌 Overview

Network hardware devices form the physical and logical foundation of modern computer networks. Each device operates at a specific layer of the OSI model to forward, filter, manage, or translate network traffic across local area networks (LANs) and wide area networks (WANs).

---

## ⚙️ Core Networking Devices

### Routers
* **Function:** Routes data packets between **different networks** (e.g., connecting a local home/office LAN to the internet/WAN).
* **OSI Layer:** Operates at **Layer 3 (Network Layer)** using logical IP addresses.
* **Key Features:** Determines the optimal path for data packets, performs Network Address Translation (NAT), and provides firewall/security boundaries between subnets.

### Switches
* **Function:** Connects multiple local devices within the **same network** (LAN) to forward data directly to the intended destination device.
* **OSI Layer:** Operates primarily at **Layer 2 (Data Link Layer)** using physical MAC addresses stored in a MAC address table.
* **Unmanaged Switches:** Plug-and-play devices with fixed configurations. No web interface, IP address, or remote management. Ideal for small office or home settings.
* **Managed Switches:** Advanced switches that allow network administrators to configure settings. Features include VLAN creation, Quality of Service (QoS), port mirroring, SNMP monitoring, and Spanning Tree Protocol (STP) to prevent switching loops.

### Hubs
* **Function:** Legacy network connection device that connects multiple Ethernet devices together.
* **OSI Layer:** Operates at **Layer 1 (Physical Layer)**.
* **Behavior:** Lacks intelligence; when data enters one port, the hub blindly broadcasts (repeats) the traffic out to **all other ports**, creating high network congestion and potential security vulnerabilities due to shared collision domains.

## 📶 Access Points & Modems

### Access Points (AP / WAP)
* **Function:** Expands a wired local network into a wireless network by broadcasting Wi-Fi signals for client devices.
* **Connection:** Plugs into a wired switch/router via Ethernet and translates 802.11 wireless signals to 802.3 wired Ethernet traffic.
* **Autonomous vs. Controller-based:** Standalone APs are configured individually; enterprise APs are managed centrally via a Wireless LAN Controller (WLC) or cloud controller.

### Cable Modems & DSL Modems
* **Cable Modem:** Uses coaxial cabling (DOCSIS standard) provided by Cable TV suppliers to transmit high-speed digital broadband signals.
* **DSL Modem:** Uses standard copper telephone lines (RJ-11) to transmit digital broadband signals while allowing simultaneous voice calls on different frequencies.

### Optical Network Terminal (ONT)
* **Function:** Converts optical light signals from a fiber-optic cable (FTTH - Fiber to the Home) into electronic Ethernet signals for local routers/switches.
* **Location:** Installed at the demarcation point (demarc) where the Internet Service Provider's fiber cable enters the building.

## ⚡ Power over Ethernet (PoE) & Infrastructure Hardware

### Power over Ethernet (PoE)
PoE delivers both electrical power and data over a single standard twisted-pair Ethernet cable (UTP Cat 5e/6), eliminating the need for dedicated AC power outlets at the device location.

* **PoE Switches:** Switches equipped with built-in PoE power delivery to directly power IP phones, security cameras, and wireless APs.
* **PoE Injectors:** Midspan devices used to add electrical power to an Ethernet cable when connecting a non-PoE switch port to a PoE-enabled end device.
* **PoE Standards:**
  * **PoE (802.3af):** Provides up to **15.4 Watts** per port.
  * **PoE+ (802.3at):** Provides up to **30 Watts** per port (for motorized PTZ cameras or dual-band APs).
  * **PoE++ / 4PPoE (802.3bt):** Provides up to **60W to 90W to 100W** per port (for video conferencing screens and high-power equipment).

### Patch Panels
* **Function:** A static panel containing rows of female RJ-45 ports on the front and punchdown blocks (110 blocks) on the rear.
* **Purpose:** Acts as a central structural point to organize bulk cabling running from wall jacks throughout a building, allowing quick and clean cross-connections to switch ports using short patch cables.

### Firewalls
* **Function:** Filters inbound and outbound network traffic based on pre-configured security rules (ACLs) to block unauthorized access.
* **Deployment:** Can be hardware appliances (positioned at the network perimeter) or software applications running on individual hosts.

### Network Interface Cards (NICs)
* **Function:** Expansion card or integrated motherboard chip that provides a physical hardware interface (Ethernet or Wi-Fi) to connect a computer to a network.
* **Identifier:** Each NIC carries a unique 48-bit **MAC address** burned into its firmware by the manufacturer.

## 🌐 Software-Defined Networking (SDN)

* **Concept:** An architecture that decouples the network control logic (**Control Plane**) from the underlying hardware that forwards traffic (**Data/Infrastructure Plane**).
* **Key Advantage:** Enables network administrators to manage, configure, and automate network traffic dynamically across virtual and physical devices using centralized software controllers and APIs rather than manually configuring individual switches and routers via CLI.

## 📊 Quick Device Comparison

| Device | Primary OSI Layer | Destination Addressing | Typical Location / Role |
| :--- | :--- | :--- | :--- |
| **Hub** | Layer 1 (Physical) | None (Broadcasts to all ports) | Legacy LAN connection |
| **Switch** | Layer 2 (Data Link) | MAC Address | Local LAN distribution |
| **Router** | Layer 3 (Network) | IP Address | Connecting LAN to WAN / Subnet routing |
| **Firewall** | Layer 3 / 4 / 7 | IP, Port, Protocol, Content | Perimeter security boundary |
| **Access Point** | Layer 2 (Data Link) | MAC Address / 802.11 Frame | Wireless LAN extension |

## ⚡ Key Vocabulary

MAC Address Table
: A memory table maintained by a switch mapping connected MAC addresses to specific physical switch ports.

Patch Panel
: A wall- or rack-mounted assembly of network ports that connects internal building cabling to network switches.

PoE Injector
: A standalone device that adds electrical power to a standard Ethernet cable to power a PoE device when using a non-PoE switch.

Software-Defined Networking (SDN)
: Network management approach that centralizes network control via software APIs, separating the control plane from the data plane.

## ⚡ Exam Tips & Pitfalls

!!! exam "Exam Tip: Hub vs. Switch Behavior"
    If a question asks about high network collisions or security eavesdropping on a local network, look for a **Hub**. Replacing a hub with a **Switch** isolates traffic into separate collision domains per port.

!!! danger "Common Pitfall: Modem vs. ONT"
    Do not confuse DSL/Cable modems with an **ONT**. Modems modulate/demodulate analog signals over copper (coaxial or phone line). An **ONT** translates optical light signals from a fiber-optic cable into digital Ethernet.

!!! tip "Remember: PoE Standards"
    * **802.3af (PoE):** ~15.4 W
    * **802.3at (PoE+):** ~30 W
    * **802.3bt (PoE++):** ~60 W to 90 W+

!!! warning "Watch Out: Managed vs. Unmanaged Switches"
    Only **Managed Switches** support VLANs, port mirroring, or remote management via SSH/SNMP. Unmanaged switches cannot separate network traffic into VLANs.

!!! example "Scenario: Installing a Wireless Access Point without AC Power"
    **Scenario:** A technician needs to mount a wireless access point in a hallway ceiling where no electrical outlets exist, and the existing network switch does not support PoE.
    
    **Solution:** Install a **PoE Injector** near the switch. Connect the switch port to the injector's LAN port, and run an Ethernet cable from the injector's PoE port up to the ceiling access point to deliver both power and data.
